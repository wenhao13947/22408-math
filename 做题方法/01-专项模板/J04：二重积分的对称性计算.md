# J04：二重积分的对称性计算

> 版本：V1.0
> 模块：数二 · 二重积分
> 前置模板：J01 直角坐标、J03 极坐标
> 关联模板：J05 复杂区域分割、J06 二重积分综合题

---

## 1. 题型定位

### 1.1 解决什么问题？

当二重积分的积分区域具有某种对称性，或者被积函数具有奇偶性时，可以利用对称关系简化计算。

主要包括三类：

1. **奇函数型：** 利用对称区域与被积函数的反对称关系，使积分直接等于零。
2. **偶函数型：** 利用对称区域与被积函数的不变关系，将积分折半或倍增。
3. **变量交换型：** 利用关于直线 y=x 的对称关系，判断交换 x、y 后的积分关系。

### 1.2 本模板的核心目标

拿到一道二重积分题，依次判断：

1. 积分区域是否对称？
2. 关于哪条轴、哪个点或哪条直线对称？
3. 被积函数在对应变换下是否保持不变？
4. 是否可以利用奇偶性消去积分？
5. 是否可以将积分区域折半？
6. 是否需要结合极坐标或区域分割？

核心原则：

**区域对称 + 被积函数满足对应关系，才能使用对称性。**

仅仅发现积分区域对称，不能直接将积分折半或令积分为零。

## 2. 题型识别

### 2.1 常见识别信号

| 题目特征 | 应当想到什么 | 原因 |
|---|---|---|
| 区域关于 x 轴对称 | 检查 f(x,y) 与 f(x,-y) | 对称点的 y 坐标互为相反数 |
| 区域关于 y 轴对称 | 检查 f(x,y) 与 f(-x,y) | 对称点的 x 坐标互为相反数 |
| 区域关于原点对称 | 检查 f(x,y) 与 f(-x,-y) | 对称点的两个坐标同时变号 |
| 区域关于 y=x 对称 | 检查 f(x,y) 与 f(y,x) | 对称点交换两个坐标 |
| 被积函数含 x、y 的奇次幂 | 检查相应坐标轴对称性 | 变号后可能产生相反数 |
| 被积函数含 x²+y² | 想到极坐标及原点对称 | 表达式具有旋转对称特征 |
| 区域是圆、圆环、正方形 | 主动检查对称性 | 常见区域具有轴对称或中心对称性质 |

### 2.2 识别时不要犯的错误

看到圆形区域，不代表任何被积函数都可以直接折半。

例如：

\[
D=\{(x,y)\mid x^2+y^2\leq 1\}
\]

区域关于 x 轴、y 轴和原点都对称。

但是：

\[
\iint_D x\,dx\,dy=0
\]

而：

\[
\iint_D (1+x)\,dx\,dy=\pi
\]

两者结果不同，原因是被积函数的对称性质不同。

因此，识别题型后必须继续检查被积函数。

## 3. 目标分析

拿到题目后，先明确当前任务。

### 3.1 题目要求求积分

目标：

\[
I=\iint_D f(x,y)\,dx\,dy
\]

先判断是否存在能够简化积分的对称关系。

### 3.2 题目要求证明积分为零

目标是寻找一个对称变换 T，使得：

1. 变换后积分区域不变；
2. 被积函数变为原来的相反数；
3. 变换的雅可比行列式绝对值为 1。

即：

\[
T(D)=D
\]

\[
f(T(x,y))=-f(x,y)
\]

于是：

\[
I=-I
\]

因此：

\[
\boxed{I=0}
\]

### 3.3 题目要求利用对称性简化积分

目标是找到两个被对称变换联系起来的区域，使两个区域上的积分相等。

例如：

\[
I=\iint_D f(x,y)\,dx\,dy
\]

若区域关于 y 轴对称，且：

\[
f(-x,y)=f(x,y)
\]

则：

\[
I=2\iint_{D_+}f(x,y)\,dx\,dy
\]

其中：

\[
D_+=D\cap\{x\geq0\}
\]

## 4. 条件挖掘

这是本模板最重要的部分。

不要只看图形，要把区域条件和函数条件都挖掘出来。

### 4.1 区域对称性判断

| 对称类型 | 对应变换 | 区域必须满足 |
|---|---|---|
| 关于 x 轴对称 | (x,y) → (x,-y) | (x,y)∈D 时，(x,-y)∈D |
| 关于 y 轴对称 | (x,y) → (-x,y) | (x,y)∈D 时，(-x,y)∈D |
| 关于原点对称 | (x,y) → (-x,-y) | (x,y)∈D 时，(-x,-y)∈D |
| 关于 y=x 对称 | (x,y) → (y,x) | (x,y)∈D 时，(y,x)∈D |

注意：

区域对称要求整个区域在对应变换下保持不变，而不只是边界看起来相似。

### 4.2 被积函数对称性判断

| 对称类型 | 检查关系 | 结论 |
|---|---|---|
| 关于 x 轴的偶性 | f(x,-y)=f(x,y) | 对应变换下不变 |
| 关于 x 轴的奇性 | f(x,-y)=-f(x,y) | 对应变换下变号 |
| 关于 y 轴的偶性 | f(-x,y)=f(x,y) | 对应变换下不变 |
| 关于 y 轴的奇性 | f(-x,y)=-f(x,y) | 对应变换下变号 |
| 关于原点的偶性 | f(-x,-y)=f(x,y) | 对应变换下不变 |
| 关于原点的奇性 | f(-x,-y)=-f(x,y) | 对应变换下变号 |
| 关于 y=x 的对称性 | f(y,x)=f(x,y) | 交换变量后不变 |
| 关于 y=x 的反对称性 | f(y,x)=-f(x,y) | 交换变量后变号 |

特别注意：

原点对称不等于分别关于 x 轴和 y 轴对称。

例如：

\[
D=\{(x,y)\mid x^2+y^2\leq1\}
\]

显然关于三个对象都对称。

但一般区域也可能只有原点对称，并不关于任意一条坐标轴对称。

### 4.3 雅可比行列式

使用变量变换时，必须考虑面积元素。

例如：

关于 y 轴对称：

\[
u=-x,\qquad v=y
\]

雅可比行列式：

\[
J=
\begin{vmatrix}
-1&0\\
0&1
\end{vmatrix}
=-1
\]

所以：

\[
|J|=1
\]

因此：

\[
dx\,dy=du\,dv
\]

其他轴对称、原点对称以及变量交换变换，也都有：

\[
|J|=1
\]

这意味着这些对称变换不会改变面积元素。

## 5. 知识联想

### 5.1 关于 x 轴对称

看到区域关于 x 轴对称，立即检查：

\[
f(x,-y)
\]

如果：

\[
f(x,-y)=-f(x,y)
\]

那么：

\[
\boxed{\iint_D f(x,y)\,dx\,dy=0}
\]

如果：

\[
f(x,-y)=f(x,y)
\]

那么上下两部分积分相等：

\[
\boxed{
\iint_D f(x,y)\,dx\,dy
=
2\iint_{D_+}f(x,y)\,dx\,dy
}
\]

其中：

\[
D_+=D\cap\{y\geq0\}
\]

### 5.2 关于 y 轴对称

看到区域关于 y 轴对称，立即检查：

\[
f(-x,y)
\]

如果：

\[
f(-x,y)=-f(x,y)
\]

则：

\[
\boxed{\iint_D f(x,y)\,dx\,dy=0}
\]

如果：

\[
f(-x,y)=f(x,y)
\]

则：

\[
\boxed{
\iint_D f(x,y)\,dx\,dy
=
2\iint_{D_+}f(x,y)\,dx\,dy
}
\]

其中：

\[
D_+=D\cap\{x\geq0\}
\]

### 5.3 关于原点对称

检查：

\[
f(-x,-y)
\]

如果：

\[
f(-x,-y)=-f(x,y)
\]

则：

\[
\boxed{\iint_D f(x,y)\,dx\,dy=0}
\]

如果：

\[
f(-x,-y)=f(x,y)
\]

则可以将区域划分成两个关于原点对应的部分，并利用两个部分积分相等。

注意：原点对称时，不能直接说左半部分和右半部分相等。

原点对称对应的是：

\[
(x,y)\longleftrightarrow(-x,-y)
\]

所以对应区域应当是关于原点变换后能够重合的两部分。

### 5.4 关于 y=x 对称

检查：

\[
f(y,x)
\]

如果：

\[
f(y,x)=-f(x,y)
\]

则：

\[
\boxed{\iint_D f(x,y)\,dx\,dy=0}
\]

如果：

\[
f(y,x)=f(x,y)
\]

则可以把区域划分为：

\[
D_1=D\cap\{x\geq y\}
\]

\[
D_2=D\cap\{y\geq x\}
\]

若两个部分在交换 x、y 后互相对应，则：

\[
\boxed{
\iint_D f(x,y)\,dx\,dy
=
2\iint_{D_1}f(x,y)\,dx\,dy
}
\]

注意：这里的折半是沿着 y=x 分割，而不是沿坐标轴分割。

### 5.5 与极坐标结合

如果区域是圆形、圆环或扇形，可以结合 J03。

极坐标：

\[
x=r\cos\theta
\]

\[
y=r\sin\theta
\]

\[
dx\,dy=r\,dr\,d\theta
\]

关于 y 轴对称时：

\[
\theta\longleftrightarrow\pi-\theta
\]

关于 x 轴对称时：

\[
\theta\longleftrightarrow-\theta
\]

原点对称时：

\[
\theta\longleftrightarrow\theta+\pi
\]

例如：

\[
x=r\cos\theta
\]

关于 y 轴变换：

\[
x\longrightarrow-x
\]

就对应：

\[
\cos(\pi-\theta)=-\cos\theta
\]

所以可以通过角度对称性判断被积函数是否变号。

## 6. 路线选择

遇到二重积分，按以下优先级判断。

### 路线 A：直接利用奇偶性，判断积分为零

适用条件：

1. 区域关于某种变换对称；
2. 被积函数在该变换下变号；
3. 对应变换的雅可比行列式绝对值为 1。

执行：

第一步：写出区域对称关系。

第二步：写出被积函数变换关系。

第三步：根据变量替换得到：

\[
I=-I
\]

第四步：

\[
\boxed{I=0}
\]

这是最优先考虑的路线，因为可以避免复杂积分计算。

### 路线 B：利用偶性折半

适用条件：

1. 区域具有对称性；
2. 被积函数在对应变换下不变；
3. 可以将区域分成两个互相对应的部分。

执行：

第一步：找到对称轴或对称变换。

第二步：确定其中一半区域。

第三步：只计算其中一半。

第四步：乘以 2。

例如：

\[
I=2\iint_{D_+}f(x,y)\,dx\,dy
\]

注意：必须确认两个对应部分的积分相等。

### 路线 C：先对称化，再计算

适用条件：

区域具有对称性，但被积函数不完全具有奇偶性。

例如：

\[
f(x,y)=1+x
\]

在关于 y 轴对称的区域上：

\[
f(x,y)=1+x
\]

可以拆分：

\[
I=\iint_D1\,dx\,dy+\iint_Dx\,dx\,dy
\]

第二项由于奇偶性为零：

\[
I=\iint_D1\,dx\,dy
\]

这种方法称为利用对称性拆分被积函数。

### 路线 D：放弃对称性，使用普通积分方法

适用条件：

1. 区域不满足对应对称条件；
2. 被积函数在变换下没有简单关系；
3. 对称性无法有效减少计算量。

此时返回：

- J01：直角坐标计算；
- J02：改变积分次序；
- J03：极坐标计算；
- J05：复杂区域分割。

不要为了使用对称性而强行使用对称性。

## 7. 完整操作流程

### 7.1 第一步：观察积分区域

先根据区域方程或不等式判断：

- 是否关于 x 轴对称？
- 是否关于 y 轴对称？
- 是否关于原点对称？
- 是否关于 y=x 对称？

如果题目没有直接给出图形，应当通过区域条件判断。

例如：

\[
D=\{(x,y)\mid x^2+y^2\leq4\}
\]

由于：

\[
(-x)^2+y^2=x^2+y^2
\]

\[
x^2+(-y)^2=x^2+y^2
\]

所以区域关于两条坐标轴对称，也关于原点对称。

### 7.2 第二步：检查被积函数

针对已经确认的对称关系，分别代入。

例如：

\[
f(x,y)=x^3y^2
\]

关于 y 轴：

\[
f(-x,y)=(-x)^3y^2=-f(x,y)
\]

因此，如果区域关于 y 轴对称：

\[
\iint_Dx^3y^2\,dx\,dy=0
\]

### 7.3 第三步：选择积分策略

| 区域对称性 | 被积函数关系 | 处理方式 |
|---|---|---|
| 对称 | 变号 | 积分为零 |
| 对称 | 不变 | 对应部分积分相等 |
| 对称 | 既有奇项又有偶项 | 拆分被积函数 |
| 不对称 | 无对应关系 | 不使用该对称性 |

### 7.4 第四步：写出严格依据

不要只写：

“由对称性可知积分为零。”

建议写：

“由于积分区域 D 关于 y 轴对称，且被积函数满足：

\[
f(-x,y)=-f(x,y)
\]

故关于 y 轴对称的两部分积分互相抵消，因此：

\[
\boxed{I=0}
\]”

### 7.5 第五步：必要时计算剩余积分

如果对称性不能直接解决问题：

1. 拆分被积函数；
2. 消去奇函数部分；
3. 对偶函数部分折半；
4. 根据区域形状选择直角坐标或极坐标；
5. 返回 J01 或 J03 完成计算。

## 8. 跨知识点连接

### 8.1 与 J01：直角坐标计算

调用时机：

- 对称性只能简化区域；
- 仍然需要计算某一半区域的积分。

具体做法：

先利用对称性缩小积分区域，再把区域表示成直角坐标下的累次积分。

### 8.2 与 J03：极坐标计算

调用时机：

- 区域是圆、圆环、扇形；
- 被积函数含有 x²+y²；
- 对称区域使用极坐标更简单。

具体做法：

先检查对称性，再转化为极坐标。

注意极坐标面积元素必须包含：

\[
r\,dr\,d\theta
\]

### 8.3 与 J05：复杂区域分割

调用时机：

- 整体区域不是简单图形；
- 但能够找到对称轴；
- 对称分割后得到简单区域。

具体做法：

先沿对称轴分割，再只计算一侧。

如果一侧仍然复杂，再调用 J05 继续分割。

### 8.4 与 J06：综合题

调用时机：

题目同时具有：

- 圆形区域；
- 奇偶函数；
- 多个积分区域；
- 复杂被积函数。

综合处理顺序：

1. 先检查是否能直接得到零；
2. 再检查是否可以折半；
3. 再判断是否拆分被积函数；
4. 最后选择坐标和积分次序。

## 9. 方法切换

### 9.1 路线 A 不能使用时

如果发现：

\[
f(T(x,y))\neq-f(x,y)
\]

不能直接得出积分为零。

继续检查是否满足：

\[
f(T(x,y))=f(x,y)
\]

如果满足，切换到路线 B。

### 9.2 路线 B 不能使用时

如果被积函数既不保持不变，也不满足反对称关系：

检查是否能够拆分：

\[
f(x,y)=f_1(x,y)+f_2(x,y)
\]

分别利用对称性处理。

### 9.3 对称性无法有效简化时

不要继续寻找复杂的对称关系。

直接切换：

- 圆形区域：优先考虑 J03；
- 普通区域：考虑 J01；
- 积分限复杂：考虑 J02；
- 区域复杂：考虑 J05。

## 10. 双版本作答

### 10.1 练习版

练习时必须完整写出：

1. 积分区域的对称性；
2. 被积函数的变换关系；
3. 对称变换对应的变量关系；
4. 必要的雅可比行列式；
5. 积分之间的关系；
6. 最终结论。

例如：

已知 D 关于 y 轴对称，求：

\[
I=\iint_Dx^3(1+y^2)\,dx\,dy
\]

由于 D 关于 y 轴对称，作变换：

\[
x=-u,\qquad y=v
\]

雅可比行列式绝对值为 1。

被积函数变为：

\[
(-u)^3(1+v^2)
=
-u^3(1+v^2)
\]

所以：

\[
I=-I
\]

因此：

\[
\boxed{I=0}
\]

### 10.2 考场版

如果对称关系明确，可以简写为：

“D 关于 y 轴对称，且被积函数关于 x 为奇函数，故由对称性：

\[
\boxed{I=0}
\]”

如果使用折半，则写清楚：

“D 关于 y 轴对称，且 f(-x,y)=f(x,y)，故：

\[
I=2\iint_{D\cap\{x\geq0\}}f(x,y)\,dx\,dy
\]”

### 10.3 最低有效作答

如果暂时无法完成计算，至少写出：

1. 能够确定的区域对称关系；
2. 能够确定的函数奇偶关系；
3. 对应的变量变换；
4. 能够确认的中间结论。

例如：

\[
D\text{ 关于 }y\text{ 轴对称}
\]

\[
f(-x,y)=-f(x,y)
\]

这两条是后续判断的有效依据。

如果没有确认区域和函数关系，不要直接写积分为零。

## 11. 例题验证

### 例题一：标准题——利用奇函数性质直接求积分

求：

\[
I=\iint_Dx\,dx\,dy
\]

其中：

\[
D=\{(x,y)\mid x^2+y^2\leq1\}
\]

#### 第一步：判断区域

D 是以原点为圆心、半径为 1 的圆盘。

区域关于 y 轴对称。

#### 第二步：判断被积函数

\[
f(x,y)=x
\]

代入：

\[
f(-x,y)=-x=-f(x,y)
\]

因此，被积函数关于 x 为奇函数。

#### 第三步：使用对称性

区域关于 y 轴对称，被积函数关于 x 为奇函数。

左右两侧积分互相抵消：

\[
I=-I
\]

所以：

\[
\boxed{I=0}
\]

#### 本题总结

触发条件：

- 圆盘区域；
- 被积函数为 x；
- 关于 y 轴对称。

看到这类结构，优先判断是否直接为零，不需要计算二重积分。

---

### 例题二：变式题——利用偶函数性质折半

求：

\[
I=\iint_Dx^2\,dx\,dy
\]

其中：

\[
D=\{(x,y)\mid x^2+y^2\leq1\}
\]

#### 第一步：判断区域

D 关于 y 轴对称。

#### 第二步：判断被积函数

\[
f(x,y)=x^2
\]

代入：

\[
f(-x,y)=(-x)^2=x^2
\]

所以：

\[
f(-x,y)=f(x,y)
\]

被积函数关于 x 为偶函数。

#### 第三步：利用对称性折半

令：

\[
D_+=D\cap\{x\geq0\}
\]

则：

\[
I=2\iint_{D_+}x^2\,dx\,dy
\]

#### 第四步：计算剩余积分

右半圆区域：

\[
0\leq x\leq1
\]

\[
-\sqrt{1-x^2}\leq y\leq\sqrt{1-x^2}
\]

所以：

\[
I=
2\int_0^1
\int_{-\sqrt{1-x^2}}^{\sqrt{1-x^2}}
x^2\,dy\,dx
\]

先对 y 积分：

\[
I=
4\int_0^1x^2\sqrt{1-x^2}\,dx
\]

令：

\[
x=\sin t
\]

则：

\[
dx=\cos t\,dt
\]

积分变为：

\[
I=4\int_0^{\pi/2}\sin^2t\cos^2t\,dt
\]

利用：

\[
\sin^2t\cos^2t=\frac{1-\cos4t}{8}
\]

得到：

\[
I=
\frac12\int_0^{\pi/2}(1-\cos4t)\,dt
\]

因此：

\[
\boxed{I=\frac{\pi}{4}}
\]

#### 本题总结

触发条件：

- 区域关于 y 轴对称；
- 被积函数关于 x 为偶函数。

可以只计算右半圆，再乘以 2。

### 例题三：变量交换——关于 y=x 的对称性

求：

\[
I=\iint_D(x-y)\,dx\,dy
\]

其中：

\[
D=[0,1]\times[0,1]
\]

#### 第一步：判断区域

D 是单位正方形。

交换 x、y 后：

\[
(x,y)\longrightarrow(y,x)
\]

区域仍然不变。

所以 D 关于直线：

\[
y=x
\]

对称。

#### 第二步：判断被积函数

\[
f(x,y)=x-y
\]

交换 x、y：

\[
f(y,x)=y-x
\]

所以：

\[
f(y,x)=-f(x,y)
\]

#### 第三步：使用对称性

区域关于 y=x 对称，被积函数交换变量后变号。

因此：

\[
I=-I
\]

得到：

\[
\boxed{I=0}
\]

#### 本题总结

不要只记住坐标轴对称。

当积分区域是正方形、圆形或其他关于 y=x 对称的区域时，也要考虑交换变量。

### 例题四：综合题——拆分被积函数后利用奇偶性

求：

\[
I=\iint_D(1+x+y)\,dx\,dy
\]

其中：

\[
D=\{(x,y)\mid x^2+y^2\leq1\}
\]

#### 第一步：判断区域

D 是单位圆盘。

区域分别关于 x 轴和 y 轴对称。

#### 第二步：拆分被积函数

\[
I=
\iint_D1\,dx\,dy
+
\iint_Dx\,dx\,dy
+
\iint_Dy\,dx\,dy
\]

#### 第三步：利用对称性处理

由于 D 关于 y 轴对称：

\[
\iint_Dx\,dx\,dy=0
\]

由于 D 关于 x 轴对称：

\[
\iint_Dy\,dx\,dy=0
\]

因此：

\[
I=\iint_D1\,dx\,dy
\]

#### 第四步：计算区域面积

D 是半径为 1 的圆盘。

所以：

\[
I=\pi
\]

最终：

\[
\boxed{I=\pi}
\]

#### 本题总结

这是非常重要的一种综合处理方式：

被积函数不一定整体是奇函数或偶函数。

可以先拆分，再分别使用对称性。

---

### 例题五：极坐标结合——利用角度对称性

求：

\[
I=\iint_Dx\,dx\,dy
\]

其中：

\[
D=\{(x,y)\mid x^2+y^2\leq1,\ y\geq0\}
\]

#### 第一步：判断区域

D 是单位上半圆。

区域关于 y 轴对称。

#### 第二步：判断被积函数

\[
f(x,y)=x
\]

满足：

\[
f(-x,y)=-f(x,y)
\]

所以可以直接得到：

\[
\boxed{I=0}
\]

#### 第三步：用极坐标验证

根据 J03：

\[
x=r\cos\theta
\]

\[
dx\,dy=r\,dr\,d\theta
\]

积分区域：

\[
0\leq r\leq1
\]

\[
0\leq\theta\leq\pi
\]

所以：

\[
I=
\int_0^\pi\int_0^1
r^2\cos\theta\,dr\,d\theta
\]

先对 r 积分：

\[
I=
\frac13\int_0^\pi\cos\theta\,d\theta
\]

因此：

\[
I=
\frac13[\sin\theta]_0^\pi
=0
\]

#### 本题总结

对称性可以直接解决问题。

极坐标也可以作为另一条计算路线。

考试中应优先选择更短、更可靠的路线。

## 12. 常见错误与验收

### 12.1 常见错误

| 错误 | 为什么错误 | 正确做法 |
|---|---|---|
| 只看区域对称就折半 | 没有确认被积函数是否对应相等 | 同时检查区域和函数 |
| 区域对称就认为积分为零 | 被积函数可能是偶函数 | 检查是否变号 |
| 把原点对称当成轴对称 | 原点对称只要求两个坐标同时变号 | 使用 (-x,-y) 检查 |
| 关于 y=x 对称却只检查 x 的奇偶性 | 这里对应的是变量交换 | 检查 f(y,x) |
| 折半后忘记乘以 2 | 漏掉另一半区域 | 明确写出对应关系 |
| 使用变量替换忘记雅可比 | 面积元素可能发生变化 | 写出绝对值行列式 |
| 只看被积函数，不看区域 | 变换后的区域可能不重合 | 先验证 T(D)=D |
| 强行使用对称性 | 对称关系可能不能简化积分 | 及时切换 J01/J03/J05 |

### 12.2 掌握验收

完成本模板后，应当能够做到：

- [ ] 判断区域关于 x 轴、y 轴、原点是否对称。
- [ ] 判断区域是否关于 y=x 对称。
- [ ] 熟练检查 f(x,-y)、f(-x,y)、f(-x,-y)。
- [ ] 熟练检查 f(y,x)。
- [ ] 能够判断什么时候积分为零。
- [ ] 能够判断什么时候可以折半。
- [ ] 能够拆分被积函数并分别使用奇偶性。
- [ ] 能够结合极坐标处理角度对称。
- [ ] 知道对称性失效时如何切换计算方法。

### 12.3 最终记忆口诀

**先看区域，再看函数；对应变号，积分为零；对应不变，两边相等；不能对应，别强行对称。**

# 附：J04 考场速查

## 一、四种核心对称关系

| 类型 | 变换 | 函数变号 | 函数不变 |
|---|---|---|---|
| x 轴对称 | (x,y)→(x,-y) | 积分为零 | 上下折半 |
| y 轴对称 | (x,y)→(-x,y) | 积分为零 | 左右折半 |
| 原点对称 | (x,y)→(-x,-y) | 积分为零 | 原点对应两部分相等 |
| y=x 对称 | (x,y)→(y,x) | 积分为零 | 沿 y=x 折半 |

## 二、标准判断流程

1. 判断区域是否对称。
2. 找到对应变换。
3. 检查被积函数是否变号或不变。
4. 变号：积分为零。
5. 不变：对应区域积分相等。
6. 不能简化：拆分函数或切换其他模板。

## 三、最重要的公式

奇函数：

\[
T(D)=D,\quad |J_T|=1,\quad f(T(x,y))=-f(x,y)
\]

则：

\[
\boxed{\iint_Df(x,y)\,dx\,dy=0}
\]

偶函数：

\[
T(D)=D,\quad |J_T|=1,\quad f(T(x,y))=f(x,y)
\]

若 D 可以分成两个被 T 互相对应的部分，则：

\[
\boxed{
\iint_Df(x,y)\,dx\,dy
=
2\iint_{D_1}f(x,y)\,dx\,dy
}
\]

注意：折半公式中的 D₁ 必须是两个对应部分中的一个完整部分。
