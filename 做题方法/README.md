# 考研数学二做题方法库

> 本目录用于建设一套面向数学二考试、以“识别条件—挖掘隐含信息—选择解题路线—规范执行—检查验证”为主线的解题方法资料。
>
> 当前状态：建设中。所有专项文件均应标明版本与状态；未经真题和变式验证的内容不得标记为最终定稿。

## 一、使用原则

1. **先识别任务，再选择方法。** 不把题目机械归类为单一知识点；综合题允许调用多个专项模板。
2. **条件必须挖掘完整。** 区分明示条件、定义直接推出的隐含条件、定理使用前提和题目限制。
3. **路线必须可执行。** 每条路线说明触发条件、适用范围、第一步、关键推导、风险及切换信号。
4. **练习版与考场版分开。** 练习版解释“为什么这样想”；考场版保留必要数学依据与规范步骤。
5. **保留最低有效作答。** 不会完整解题时，只写确定正确的定义、条件、合法关系和可靠中间结论，不编造公式。
6. **每个文件独立提交。** 每完成一个文件即单独提交，减少长任务中断造成的成果损失。
7. **先完成模块，再综合验收。** 单个模板初稿不等于模块完成；需用标准题、变式题、综合题验证后再统一优化。

## 二、统一专项模板结构

每个专项文件原则上包含以下十二部分：

1. 题型定位
2. 题型识别
3. 目标分析
4. 条件挖掘
5. 知识联想
6. 路线选择
7. 完整操作流程
8. 跨知识点连接
9. 方法切换
10. 双版本作答（练习版、考场版、最低有效作答）
11. 例题验证（标准题、变式题、综合题）
12. 常见错误与验收

根据题型特点可以调整小节，但不得为了套模板而加入无意义内容。

## 四、单文件质量标准

每个文件提交前至少检查：

- 数学结论、公式、定理前提是否准确；
- 推导是否存在跳步、循环论证或隐含条件遗漏；
- 例题答案是否独立复算；
- 例题是否覆盖模板宣称的适用范围；
- 是否说明方法失效的情形和替代路线；
- LaTeX 是否使用标准数学定界符与语法；
- 目录链接、文件名和交叉引用是否一致；
- 是否明确标记“初稿 / 已验证 / 待统一优化”。
