# 线性代数判定关系速查

> V1.0｜速查初稿

| 主题 | 判定关系 | 易错点 |
|---|---|---|
| 可逆矩阵 | \(|A|\ne0\iff r(A)=n\) | 只适用于 n 阶方阵 |
| 矩阵秩 | 初等行变换不改变秩 | 列向量主元回到原矩阵识别 |
| 线性相关 | 齐次系数方程有非零解 | 向量个数多于维数必相关 |
| 非齐次方程组有解 | \(r(A)=r(A|b)\) | 比较系数矩阵和增广矩阵 |
| 唯一解 | 相容且 \(r(A)=n\) | n 为未知数个数 |
| 齐次方程非零解 | \(r(A)<n\) | 零解永远存在 |
| 特征值 | \(|A-\lambda I|=0\) | 特征向量不能为零向量 |
| 特征向量空间维数 | \(n-r(A-\lambda I)\) | 几何重数不超过代数重数 |
| 可对角化 | 有 n 个线性无关特征向量 | 互异特征值是充分条件 |
| 实对称矩阵 | 可正交对角化 | 一般矩阵不保证 |
| 二次型正定 | 对称矩阵特征值全正 | 顺序主子式判据要求对称矩阵 |

> 使用前确认矩阵阶数、实数域/复数域及题目给定条件。
