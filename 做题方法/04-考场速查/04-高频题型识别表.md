# 高频题型识别表

> V1.0｜速查初稿

## 高等数学

| 题目线索 | 首先识别 | 首选入口 | 关键检查 |
|---|---|---|---|
| \(0/0\)、\(\infty/\infty\) | 未定式 | 代数化简/等价/泰勒/洛必达 | 定理前提、主项抵消 |
| \(1^\infty\)、\(0^0\)、\(\infty^0\) | 幂指型 | 取对数 | 底数正、对数极限 |
| 分段函数求极限 | 左右极限 | 分左右 | 左右相等 |
| \(a_{n+1}=F(a_n)\) | 递推数列 | 有界、单调 | 先证明收敛 |
| 差商 | 导数定义 | 凑定义 | 趋近点和分子对应 |
| 切线/法线 | 几何导数 | 求点值与斜率 | 法线斜率特殊情形 |
| 证明不等式 | 辅助函数 | 移项、求导 | 定义域与等号 |
| 求最值 | 极值/闭区间最值 | 导数符号 | 端点、驻点、不可导点 |
| \(\int_a^x f(t)dt\) | 变上限积分 | 微积分基本定理 | 上下限链式因子 |
| \(\iint_D\) | 二重积分 | 先画区域 | 积分限、雅可比 |
| \(y'+Py=Q\) | 一阶线性方程 | 积分因子 | 标准形式 |

## 线性代数

| 题目线索 | 首先识别 | 首选入口 | 关键检查 |
|---|---|---|---|
| 行列式计算 | 行列式性质 | 初等变换/展开 | 变号与倍数 |
| \(A^{-1}\) | 可逆性 | 行列式或消元 | 方阵且行列式非零 |
| 求秩 | 主元个数 | 阶梯形 | 参数特殊值 |
| 向量相关 | 齐次方程/矩阵秩 | 列向量矩阵 | 原向量组 |
| \(Ax=b\) | 方程组 | 增广矩阵 | 秩判据 |
| \(|A-\lambda I|=0\) | 特征值 | 特征方程 | 重数 |
| 相似对角化 | 特征向量组 | 求特征子空间 | 是否有 n 个无关向量 |
| 二次型 | 对称矩阵 | 配方/正交变换 | 相似与合同区分 |

> 本表只负责“第一眼定位”，完整条件和步骤以对应专项文件为准。
