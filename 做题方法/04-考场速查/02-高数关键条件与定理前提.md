# 高数关键条件与定理前提速查

> V1.0｜速查初稿

| 知识 | 使用前提/结论 | 高频误区 |
|---|---|---|
| 可导推出连续 | 在该点可导 | 连续不推出可导 |
| 极限四则运算 | 有限极限；商分母极限非零 | 分母趋零不能直接套商法则 |
| 洛必达 | \(0/0\)、\(\infty/\infty\) 且满足可导条件 | 不是通用求极限法 |
| 等价无穷小 | 乘除结构中适当替换 | 差式中主项可能抵消 |
| 单调有界数列 | 单调且有界 | 有界本身不保证收敛 |
| 闭区间最值定理 | 闭区间连续 | 开区间不保证取得最值 |
| Lagrange 中值 | 闭区间连续、开区间可导 | 漏掉区间条件 |
| 二元极限不存在 | 两条路径极限不同即可 | 多条路径相同不能证明存在 |
| 偏导存在 | 仅说明坐标方向导数存在 | 不必然可微 |
| 连续偏导 | 在邻域满足相应条件时可作为可微充分条件 | 不要误作必要条件 |
| 变上限积分求导 | 被积函数连续等条件 | 上下限同时变化时漏下限项 |
| 二重积分极坐标 | 面积元带 r | 漏雅可比 |
| 对称性积分 | 区域和被积函数均满足对应对称 | 只看区域不够 |

> 速查表用于提醒前提，正式证明仍应回到对应专项模板。
