# 最低有效作答手册

> V1.0｜速查初稿

## 一、原则
不会完整解题时，争取写出确定正确的定义、条件、方程、变形或中间结论。最低有效作答不是堆砌公式，而是留下与题目直接相关、可被判分的数学步骤。

## 二、高数常见入口

| 题型 | 可先写的有效内容 |
|---|---|
| 极限 | 趋近方向、直接代入结果、未定式类型 |
| 分段极限 | 左右极限表达式 |
| 导数 | 导数定义或正确求导公式 |
| 中值定理 | 定理前提与存在点关系式 |
| 单调性 | 一阶导数及其符号 |
| 最值 | 定义域、驻点和端点候选集 |
| 定积分 | 正确积分区间和被积函数 |
| 二重积分 | 区域描述、积分限或坐标变换 |
| 微分方程 | 标准形式、变量分离式或特征方程 |

## 三、线代常见入口

| 题型 | 可先写的有效内容 |
|---|---|
| 行列式 | 可用的行列式性质 |
| 逆矩阵 | \(|A|\ne0\) 的可逆判据 |
| 秩 | 合法初等行变换和阶梯形 |
| 线性相关 | 系数齐次方程 |
| 非齐次方程组 | 增广矩阵及秩判据 |
| 特征值 | \(|A-\lambda I|=0\) |
| 对角化 | 特征向量线性无关条件 |
| 二次型 | 对称矩阵表达式 |

## 四、绝对不要写
- 不满足条件的洛必达或中值定理；
- 未证明收敛就对递推式直接取极限；
- 把偏导存在当作可微；
- 把矩阵乘法当成可交换；
- 把相似变换和合同变换混为一谈；
- 不确定的结果或凭印象写出的公式。

## 五、考场最后检查
题目要求是否完成？参数特殊值是否遗漏？定理前提是否成立？答案是否写清楚？
