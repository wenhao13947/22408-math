# 解题路线切换表

> V1.0｜速查初稿

| 当前路线 | 发现的问题 | 立即停止的错误做法 | 转换方向 |
|---|---|---|---|
| 极限直接代入 | 不连续/未定式 | 强行代入 | 左右分析或未定式变形 |
| 等价无穷小 | 差式抵消 | 逐项盲换 | 泰勒展开 |
| 洛必达 | 导数后更复杂 | 无限次求导 | 代数化简、泰勒、夹逼 |
| 数列递推求极限 | 未证收敛 | 直接令递推极限 | 单调有界或夹逼 |
| 导数判单调 | 导数符号难判 | 盲目展开 | 因式分解、辅助函数 |
| 多元极限路径 | 路径结果相同 | 宣称极限存在 | 极坐标、统一估计 |
| 二重积分直角坐标 | 积分限复杂 | 强行积分 | 换序或极坐标 |
| 换元积分 | 新式更复杂 | 继续硬算 | 换元重选或代数拆分 |
| 矩阵求逆公式 | 计算过长 | 展开大量代数余子式 | Gauss-Jordan |
| 秩的行化简 | 主元含参数 | 直接约分参数 | 特殊参数分类 |
| 特征值 | 特征多项式复杂 | 盲目展开 | 利用结构、迹和行列式检查 |
| 对角化 | 特征向量不足 | 强行构造可逆 P | 判定不可对角化 |
| 二次型配方 | 交叉项复杂 | 随意换变量 | 正交对角化或主子式判据 |

## 三条底线
1. 条件不满足，立即停止使用该定理。
2. 出现特殊参数，先分情况，不要直接约去。
3. 任何路线切换都要回到题目原目标，确认新表达式仍与原题等价。
