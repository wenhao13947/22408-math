# A01｜未定式与常用变形

> 版本：V1.0｜状态：初稿，待真题与变式验证  
> 目标：识别未定式的真实结构，先用代数变形降低复杂度，再选择等价无穷小、泰勒、洛必达或夹逼。

## 1. 题型定位

未定式不是极限值，而是直接代入后无法判断结果的表达形式。常见七类：

\[
\frac00,\quad\frac{\infty}{\infty},\quad
0\cdot\infty,\quad\infty-\infty,\quad
1^\infty,\quad0^0,\quad\infty^0.
\]

看到未定式，第一任务不是立刻套定理，而是判断能否通过因式分解、有理化、通分、取对数或变量代换改写成更容易处理的形式。

## 2. 题型识别

| 代入形式 | 识别 | 常用变形 |
|---|---|---|
| \(0/0\) | 分子分母同时趋零 | 因式分解、约分、有理化、等价、泰勒、洛必达 |
| \(\infty/\infty\) | 分子分母同时无界 | 提取主导项、同除最高阶、洛必达 |
| \(0\cdot\infty\) | 趋零量乘无界量 | 改写成商 |
| \(\infty-\infty\) | 两个无界量相减 | 通分、合并根式、有理化、提取主导项 |
| \(1^\infty\) | 底数趋 1、指数无界 | 取对数 |
| \(0^0\) | 底数趋零、指数趋零 | 取对数，先确认底数为正 |
| \(\infty^0\) | 底数无界、指数趋零 | 取对数 |

## 3. 目标分析

每道题按顺序回答：
1. 直接代入是什么形式？
2. 哪个部分趋零、哪个部分无界？
3. 是否存在显然的代数结构可以先简化？
4. 变形后能否得到基本极限或熟悉的未定式？
5. 选择的定理前提是否满足？

## 4. 条件挖掘

| 已知 | 可用信息 | 操作 |
|---|---|---|
| 分子分母均趋零 | 可能为 \(0/0\) | 找公共因子、比较阶数 |
| 两个根式之差 | 共轭式可消去根式差 | 乘共轭并检查新分母 |
| 两个无穷大量相减 | 可能主导项抵消 | 通分或提取共同主导项 |
| 底数趋于 1 且指数无界 | 可能为 \(1^\infty\) | 设 \(y=f(x)^{g(x)}\)，取对数 |
| \(f(x)\to0\)、\(g(x)\to\infty\) | 乘积型 | 改写为 \(f/(1/g)\) 或 \(g/(1/f)\) |
| 可导且满足未定式 | 可考虑洛必达 | 检查区间可导和导数商极限 |

## 5. 知识联想

- 因式分解：多项式在零点附近常含 \(x-a\) 因子。
- 有理化：\(\sqrt A-\sqrt B\) 乘以共轭后变为 \((A-B)/(\sqrt A+\sqrt B)\)。
- 通分：处理两个分式之差，避免分别估计两个无穷大。
- 等价无穷小：适用于乘除结构，差式需谨慎。
- 泰勒展开：低阶项抵消时寻找首个非零项。
- 洛必达：仅在 \(0/0\)、\(\infty/\infty\) 且满足定理条件时使用。
- 取对数：处理幂指型，求 \(\ln y=g\ln f\)，再还原。

## 6. 路线选择

### A：先做代数变形
触发：表达式含因子、根式差、分式差。
1. 因式分解或通分；
2. 根式差乘共轭；
3. 约去非零邻域因子；
4. 重新代入判断。
风险：约分只能在去心邻域内合法，不能把趋近点处的函数值当作依据。

### B：改写为标准未定式
触发：乘积型或差式型。
- \(0\cdot\infty\)：改写成商；
- \(\infty-\infty\)：通分、有理化或提取主导项；
- 幂指型：取对数。
风险：改写后必须重新判断极限形式，不能沿用原来的判断。

### C：调用极限定理
触发：变形后仍为 \(0/0\) 或 \(\infty/\infty\)，或存在明显阶数抵消。
- 等价无穷小：乘除结构；
- 泰勒：差式抵消；
- 洛必达：满足可导等条件；
- 夹逼：存在可用上下界。

## 7. 完整操作流程

1. 写出直接代入形式。
2. 圈出趋零项和无界项。
3. 检查因式分解、约分、通分、有理化。
4. 若为乘积型或差式型，先改写。
5. 若为幂指型，设 \(y=\cdots\)，取对数。
6. 再次识别新形式。
7. 选择最短且合法的专项方法。
8. 检查变形是否在去心邻域成立，检查定理条件。
9. 写出结果并复核符号、阶数。

## 8. 跨知识点连接

| 当前结构 | 调用模板 |
|---|---|
| 乘除结构中的无穷小 | 等价无穷小与阶数比较 |
| 多项式或函数项抵消 | 泰勒展开与主导项抵消 |
| 合法的 \(0/0\)、\(\infty/\infty\) | 洛必达法则 |
| 有界振荡与趋零量 | 夹逼定理与有界性 |
| 变量趋于无穷 | 无穷远极限与渐近线 |

## 9. 方法切换

| 卡住情况 | 切换 |
|---|---|
| 因式分解无效 | 有理化、通分或泰勒 |
| 等价替换后仍有抵消 | 泰勒展开 |
| 洛必达后更复杂 | 停止求导，回到代数变形或阶数比较 |
| 乘积改写后分母复杂 | 尝试倒数结构或夹逼 |
| 幂指取对数后仍复杂 | 先化简对数表达式，再用等价或泰勒 |

## 10. 双版本作答

**练习版：**写出原始未定式、变形理由、变形后的极限类型、方法前提及最终计算。

**考场版：**保留关键等式和方法依据。例如：
\[
\sqrt{1+x}-1
=\frac{x}{\sqrt{1+x}+1},
\]
再代入或继续计算。

**最低有效作答：**正确识别未定式，写出合法的有理化、通分或取对数关系；不确定时不要冒用洛必达。

## 11. 例题验证

### 例 1：\(0/0\) 因式分解
\[
\lim_{x\to1}\frac{x^2-1}{x-1}
=\lim_{x\to1}(x+1)=2.
\]
因式分解后在 \(x\ne1\) 的去心邻域内约分合法。

### 例 2：根式差有理化
\[
\lim_{x\to0}\frac{\sqrt{1+x}-1}{x}
=\lim_{x\to0}\frac{1}{\sqrt{1+x}+1}
=\frac12.
\]

### 例 3：\(0\cdot\infty\) 改写
\[
\lim_{x\to0^+}x\ln x
=\lim_{x\to0^+}\frac{\ln x}{1/x}.
\]
为 \(-\infty/\infty\) 型，洛必达得
\[
\lim_{x\to0^+}\frac{1/x}{-1/x^2}
=\lim_{x\to0^+}(-x)=0.
\]

### 例 4：\(\infty-\infty\) 有理化
\[
\lim_{x\to\infty}(\sqrt{x^2+x}-x)
=\lim_{x\to\infty}\frac{x}{\sqrt{x^2+x}+x}
=\frac12,
\]
这里 \(x\to+\infty\)，分母提取 \(x\) 后得到 \(1/(\sqrt{1+1/x}+1)\)。

### 例 5：幂指型取对数
\[
L=\lim_{x\to0}(1+3x)^{1/x}.
\]
底数在充分小的邻域内为正。取对数：
\[
\ln L=\lim_{x\to0}\frac{\ln(1+3x)}x=3,
\]
故 \(L=e^3\)。

## 12. 常见错误与验收

- [ ] 未定式只是一种形式，没有把它当作答案。
- [ ] 代数变形在去心邻域内合法。
- [ ] 根式有理化没有漏掉共轭分母。
- [ ] \(\infty-\infty\) 没有拆成两个极限分别相减。
- [ ] 等价无穷小没有在易发生抵消的差式中盲目替换。
- [ ] 洛必达只用于符合条件的两类未定式。
- [ ] 幂指型取对数时底数为正，最后正确还原。
