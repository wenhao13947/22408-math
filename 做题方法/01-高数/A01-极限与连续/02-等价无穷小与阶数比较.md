# A01-02｜等价无穷小与阶数比较

> 版本：V1.0  
> 状态：初稿，待真题与综合题交叉验证  
> 核心任务：识别趋于零的基本表达式，判断能否用等价无穷小替换，并在多个无穷小量之间比较阶数。  
> 前置文件：[极限计算总流程](./01-极限计算总流程.md)

## 1. 题型定位

当 \(x\to a\) 时，若函数 \(f(x)\to0\)，称 \(f(x)\) 为该过程中的无穷小量。

若 \(f(x)\to0,\ g(x)\to0\)，且

\[
\lim_{x\to a}\frac{f(x)}{g(x)}=1,
\]

则称 \(f(x)\) 与 \(g(x)\) 是等价无穷小，记作：

\[
f(x)\sim g(x)\qquad(x\to a).
\]

等价无穷小的本质是：在当前趋近过程中，两者的比值趋于 1，因此它们具有相同的首要数量级。

**它主要用于乘积、商中的化简；不能在差式中不加判断地逐项替换。**

## 2. 题型识别：看到什么，想到什么

| 题目特征 | 数学结构 | 首要动作 |
|---|---|---|
| \(x\to0\)，出现 \(\sin x\)、\(\tan x\) | 三角函数型无穷小 | 考虑替换为 \(x\) |
| 出现 \(e^x-1\)、\(\ln(1+x)\) | 指数、对数型无穷小 | 考虑替换为 \(x\) |
| 出现 \(1-\cos x\) | 二阶无穷小 | 考虑替换为 \(x^2/2\) |
| 出现 \(\sqrt{1+x}-1\) | 根式差 | 有理化或替换为 \(x/2\) |
| 出现 \(\sin(3x)\)、\(\ln(1+2x)\) | 复合自变量趋于零 | 先确认内部变量趋于零，再按内部变量替换 |
| 分子、分母均由多个小量相乘组成 | 阶数比较 | 分别确定每个因子的阶 |
| 分子是两个近似相等表达式之差 | 主导项抵消 | 不要直接逐项等价替换，考虑泰勒展开 |

## 3. 目标分析

做题时要完成三件事：

1. **找出无穷小量：**确认每个表达式确实趋于零。
2. **选出等价表达式：**把复杂小量替换成更简单、同阶的表达式。
3. **判断替换位置是否合法：**尤其检查是否处于差式中。

如果最终目标是求一个商，常见做法是分别替换分子、分母中的等价无穷小；如果目标是求差，通常需要更高阶展开。

## 4. 条件挖掘

| 条件 | 可以推出 | 对解题的作用 |
|---|---|---|
| \(u(x)\to0\) | \(\sin u\sim u\) | 三角函数化简 |
| \(u(x)\to0\) | \(\tan u\sim u\) | 正切化简 |
| \(u(x)\to0\) | \(e^u-1\sim u\) | 指数表达式化简 |
| \(u(x)\to0\) | \(\ln(1+u)\sim u\) | 对数表达式化简 |
| \(u(x)\to0\) | \(1-\cos u\sim u^2/2\) | 二阶无穷小识别 |
| \(u(x)\to0\) 且 \(u(x)\ne0\) 在去心邻域内成立 | 可在商中按等价关系化简 | 约分时仍需注意定义域 |
| \(f\sim g,\ g\sim h\) | \(f\sim h\) | 可串联替换 |
| \(f\sim g\) | \(f-g=o(g)\) | 理解误差比主项更高阶 |

这里 \(o(g)\) 表示相对于 \(g\) 更高阶的小量，即：

\[
\frac{o(g)}{g}\to0.
\]

## 5. 知识联想：常用等价无穷小

以下关系均在自变量趋于相应极限、且内部变量 \(u\to0\) 时成立。

### 5.1 一阶等价无穷小

\[
\sin u\sim u,\qquad \tan u\sim u,
\]

\[
\arcsin u\sim u,\qquad \arctan u\sim u,
\]

\[
e^u-1\sim u,\qquad \ln(1+u)\sim u,
\]

\[
a^u-1\sim u\ln a\quad(a>0,\ a\ne1),
\]

\[
(1+u)^\alpha-1\sim\alpha u\quad(\alpha\ne0).
\]

### 5.2 二阶及更高阶常用关系

\[
1-\cos u\sim\frac{u^2}{2},
\]

\[
u-\sin u\sim\frac{u^3}{6},
\]

\[
\tan u-u\sim\frac{u^3}{3},
\]

\[
\ln(1+u)-u\sim-\frac{u^2}{2},
\]

\[
e^u-1-u\sim\frac{u^2}{2}.
\]

这些高阶关系可由泰勒展开得到。若题目存在多项抵消，应优先明确展开依据，不要只靠记忆猜阶数。

### 5.3 复合形式的替换

若 \(u(x)\to0\)，则：

\[
\sin u(x)\sim u(x),
\]

\[
1-\cos u(x)\sim\frac{u(x)^2}{2},
\]

\[
\ln(1+u(x))\sim u(x).
\]

例如 \(x\to0\) 时：

\[
\sin(3x)\sim3x,\qquad
1-\cos(2x)\sim2x^2.
\]

## 6. 路线选择

### 路线 A：乘积或商中直接替换

**触发条件：**待处理表达式为乘积或商，且每个被替换因子都满足相应等价关系。

例如：

\[
\lim_{x\to0}\frac{\sin 2x}{\ln(1+3x)}
=
\lim_{x\to0}\frac{2x}{3x}
=\frac23.
\]

**为什么可行：**分子、分母分别与替代量等价，商的极限可由比值关系得到。

### 路线 B：先提取主导因子，再比较阶数

**触发条件：**表达式中有多个因子或幂次，需要比较整体数量级。

例如：

\[
\frac{\sin^2x\,(1-\cos x)}{x^4}
\sim
\frac{x^2\cdot x^2/2}{x^4}
=\frac12.
\]

### 路线 C：差式抵消，转泰勒展开

**触发条件：**出现 \(f(x)-g(x)\)，且两项等价或首项相同。

此时 \(f\sim g\) 只能说明二者相对接近，不能直接得出 \(f-g\) 的主导项。

例如：

\[
\sin x-x
\]

不能把 \(\sin x\) 直接替换成 \(x\)，然后说差为零。应展开：

\[
\sin x-x=-\frac{x^3}{6}+o(x^3).
\]

### 路线 D：有理化后再比较阶数

**触发条件：**根式差导致结构不清楚。

例如：

\[
\sqrt{1+x}-1
=\frac{x}{\sqrt{1+x}+1}
\sim\frac{x}{2}.
\]

## 7. 完整操作流程

1. 写出趋近过程，例如 \(x\to0\)。
2. 检查复合变量是否趋于零。
3. 圈出可使用的基本等价无穷小。
4. 判断整体是乘积、商还是差式。
5. 若为乘积或商，逐因子替换并保留系数、幂次。
6. 若为差式，检查首项是否抵消；若抵消，转泰勒展开。
7. 对复合变量正确处理系数，例如 \(\sin(5x)\sim5x\)，不是 \(x\)。
8. 化简后计算极限。
9. 检查替换是否改变了主导项、是否遗漏常数因子。

## 8. 阶数比较：如何判断谁更小

若 \(f(x),g(x)\to0\)，常用比较方式：

- 若 \(f/g\to0\)，则 \(f\) 是比 \(g\) 更高阶的无穷小；
- 若 \(f/g\to c\ne0\)，则二者同阶；
- 若 \(|f/g|\to\infty\)，则 \(f\) 是比 \(g\) 更低阶的无穷小。

例如 \(x\to0\) 时：

\[
x^2=o(x),\qquad x^3=o(x^2).
\]

常见数量级（仅用于相应变量趋于零的情形）：

\[
1-\cos x=O(x^2),\quad
\sin x-x=O(x^3),\quad
e^x-1-x=O(x^2).
\]

注意：\(O(x^n)\) 只表示不超过该数量级的控制，不等同于“等价于 \(x^n\)”。要判断等价，需要比值极限为非零常数；要判断精确主导项，需给出更具体展开。

## 9. 方法切换

| 当前情况 | 触发信号 | 切换方法 |
|---|---|---|
| 等价替换后差式变成 0 | 原表达式两项主项抵消 | 泰勒展开 |
| 不确定应保留几阶 | 一阶项抵消 | 至少展开到可能出现的下一非零阶 |
| 根式差不易比较 | 分子有两个根式或根式减常数 | 有理化 |
| 复合函数自变量不明显 | 内部函数趋于某个值而非 0 | 先作变量平移或按对应点展开 |
| 替换后仍是 \(0/0\) | 主导阶数仍相同 | 保留更高阶项或换路线 |
| 需要比较两个复杂无穷小 | 直接等价关系难找 | 计算比值极限定义阶数 |

## 10. 双版本作答

### 10.1 练习版

1. 先确认 \(u(x)\to0\)。
2. 写出使用的等价无穷小。
3. 说明表达式属于乘积、商还是差式。
4. 若是差式，说明是否发生主项抵消。
5. 写出替换后的表达式。
6. 化简并求极限。
7. 若使用高阶关系，注明由哪一阶泰勒展开得到。

### 10.2 考场版

例如：

\[
\begin{aligned}
\lim_{x\to0}\frac{\sin 2x}{\ln(1+3x)}
&=\lim_{x\to0}\frac{2x}{3x}\\
&=\frac23.
\end{aligned}
\]

若为差式，不可只写“等价无穷小代换”，必须展示足够阶数的展开。

### 10.3 最低有效作答

至少写出：
- 内部变量趋于零；
- 对应的正确等价关系；
- 替换后的主导表达式；
- 若发生抵消，指出需要更高阶展开。

不要在差式中用粗略替换制造错误结论。

## 11. 例题验证

### 例 1：标准题——三角函数与对数之商

求：

\[
\lim_{x\to0}\frac{\sin 4x}{\ln(1+2x)}.
\]

因为 \(4x\to0,\ 2x\to0\)，所以：

\[
\sin4x\sim4x,\qquad
\ln(1+2x)\sim2x.
\]

因此：

\[
\boxed{\lim_{x\to0}\frac{\sin4x}{\ln(1+2x)}=2}.
\]

### 例 2：变式题——多个因子比较阶数

求：

\[
\lim_{x\to0}
\frac{(1-\cos 2x)\sin 3x}{x^3}.
\]

有：

\[
1-\cos2x\sim\frac{(2x)^2}{2}=2x^2,
\qquad \sin3x\sim3x.
\]

故：

\[
\boxed{
\lim_{x\to0}
\frac{(1-\cos2x)\sin3x}{x^3}
=6
}.
\]

### 例 3：综合题——差式不能直接等价替换

求：

\[
\lim_{x\to0}\frac{\sin x-x}{x^3}.
\]

利用泰勒展开：

\[
\sin x=x-\frac{x^3}{6}+o(x^3).
\]

所以：

\[
\frac{\sin x-x}{x^3}
=-\frac16+o(1),
\]

从而：

\[
\boxed{-\frac16}.
\]

### 例 4：根式差的有理化

求：

\[
\lim_{x\to0}\frac{\sqrt{1+2x}-1}{x}.
\]

有理化：

\[
\begin{aligned}
\frac{\sqrt{1+2x}-1}{x}
&=\frac{2x}{x(\sqrt{1+2x}+1)}\\
&=\frac{2}{\sqrt{1+2x}+1}
\longrightarrow1.
\end{aligned}
\]

故极限为：

\[
\boxed{1}.
\]

## 12. 常见错误与验收

### 常见错误

1. 不确认内部变量趋于零，就套用基本等价无穷小。
2. 忘记复合自变量中的系数，如 \(\sin 3x\sim3x\)。
3. 在差式中直接把两个等价无穷小替换，导致主项抵消信息丢失。
4. 把同阶、等价和高阶混为一谈。
5. 忽略常数因子和幂次。
6. 把 \(O(x^n)\) 当成一定等价于 \(x^n\)。
7. 变量趋于无穷时，不经换元就机械套用 \(x\to0\) 的公式。
8. 只凭记忆使用高阶等价关系，却没有确认其适用趋近过程。

### 验收清单

- [ ] 每个内部变量的趋近状态正确；
- [ ] 等价无穷小公式及常数系数正确；
- [ ] 替换位置属于合法的乘积或商结构；
- [ ] 差式中的主项抵消已被识别；
- [ ] 阶数、同阶、等价的概念没有混淆；
- [ ] 高阶项足以支撑所求极限；
- [ ] 最终极限经过独立检查。

## 考场速查

**先看结构，再换等价。**

- \(\sin u,\tan u,\arcsin u,\arctan u\sim u\)；
- \(e^u-1,\ln(1+u)\sim u\)；
- \(1-\cos u\sim u^2/2\)；
- \(\sqrt{1+u}-1\sim u/2\)；
- \(u-\sin u\sim u^3/6\)；
- \(\tan u-u\sim u^3/3\)。

**使用边界：**

- 乘积、商：通常可逐因子替换；
- 差式：先检查主项抵消，必要时泰勒展开；
- 复合形式：先确认内部变量趋于零；
- 阶数判断：看比值极限，不凭外观猜测。
