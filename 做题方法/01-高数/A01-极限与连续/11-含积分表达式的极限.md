# A01｜含积分表达式的极限

> 版本：V1.0｜状态：初稿，待真题与变式验证  
> 目标：遇到积分随参数变化时，先判断能否用连续性、积分中值定理或夹逼，再决定是否需要积分估计、变量代换或微积分基本定理。

## 1. 题型定位

常见结构包括：
\[
\lim_{x\to a}\int_a^x f(t)\,dt,\qquad
\lim_{x\to0}\frac1x\int_0^x f(t)\,dt,
\]
以及积分区间、被积函数或参数同时变化的表达式。

## 2. 题型识别

| 结构 | 优先联想 |
|---|---|
| 积分上限趋于下限 | 积分区间长度趋零 |
| 积分平均值 \(\frac1{x-a}\int_a^x f\) | 积分中值定理或连续性 |
| 积分内含参数 | 一致估计、夹逼、连续性 |
| \(\frac1{x}\int_0^x f(t)dt\) | 变上限积分平均值 |
| 积分内出现振荡 | 绝对值估计、夹逼 |

## 3. 目标分析

先确认：
1. 积分区间是否收缩到一点？
2. 被积函数是否在相关点连续或有界？
3. 是否能用积分中值定理？
4. 分母是否与区间长度同阶？
5. 若被积函数含参数，是否能找到对参数一致有效的控制？

## 4. 条件挖掘

| 条件 | 推论 | 用法 |
|---|---|---|
| \(f\) 在 \(a\) 连续 | 区间内函数值接近 \(f(a)\) | 积分平均值趋于 \(f(a)\) |
| \(|f(t)|\le M\) | 积分绝对值不超过区间长度乘 \(M\) | 夹逼 |
| \(f\) 在闭区间连续 | 有界且可积 | 可用积分中值定理 |
| 积分上限 \(x\to a\) | 区间长度趋零 | 估计积分量级 |
| 变上限积分 \(F(x)=\int_a^x f(t)dt\) 且 \(f\) 连续 | \(F'(x)=f(x)\) | 微积分基本定理 |

## 5. 知识联想

### 积分估计
若 \(|f(t)|\le M\)，则
\[
\left|\int_a^b f(t)dt\right|
\le M|b-a|.
\]

### 积分中值定理
若 \(f\) 在 \([a,b]\) 连续，则存在 \(\xi\) 位于 \(a,b\) 之间，使
\[
\int_a^b f(t)dt=f(\xi)(b-a).
\]

### 变上限积分求导
若 \(f\) 在包含 \(x\) 的区间连续，则
\[
\frac{d}{dx}\int_a^x f(t)dt=f(x).
\]

## 6. 路线选择

### A：连续性与积分中值
适合积分平均值。将积分写为 \(f(\xi)\) 乘区间长度，再利用 \(\xi\to a\)。

### B：绝对值估计与夹逼
适合被积函数有界或可被简单函数控制的情况：
\[
\left|\int_a^x f(t)dt\right|
\le M|x-a|.
\]

### C：微积分基本定理或变量代换
适合变上限积分的导数型极限，或需要将积分区间标准化的情况。若用洛必达，必须先确认分子分母构成合法未定式，且积分函数可导。

## 7. 完整操作流程

1. 标明积分上下限及趋近参数。
2. 计算区间长度。
3. 检查被积函数的连续性、有界性。
4. 判断使用积分中值还是绝对值估计。
5. 若分母与区间长度抵消，计算剩余平均值。
6. 若出现变上限积分的差商，考虑导数定义或微积分基本定理。
7. 参数同时变化时，检查估计是否对整个积分区间成立。
8. 最后检查积分方向：交换上下限会改变符号。

## 8. 跨知识点连接

- 夹逼定理：控制积分绝对值。
- 连续性：将积分平均值的极限转为函数值。
- 导数定义：将积分表达式与差商联系。
- 定积分性质：区间可加性、换元与积分中值。
- 洛必达：仅作为满足条件时的备选，不应替代简单的积分估计。

## 9. 方法切换

- 不知道积分内函数具体值：先找上下界。
- 中值定理不适用（连续性缺失）：尝试可积性与绝对值估计。
- 估计太粗：利用被积函数在点附近的连续性细化。
- 积分区间不收缩：不能直接使用“长度趋零”论证，需另行分析。

## 10. 双版本作答

**练习版：**写明区间长度、被积函数性质、使用定理的前提和估计过程。

**考场版：**直接写出关键估计或积分中值表达式，并说明连续性条件。

**最低有效作答：**至少写出积分绝对值估计，或正确的积分中值定理表达式。

## 11. 例题验证

### 例 1：积分平均值
设 \(f\) 在 \(0\) 处连续，求
\[
\lim_{x\to0}\frac1x\int_0^x f(t)dt.
\]
由积分中值定理，存在介于 \(0\) 与 \(x\) 之间的 \(\xi\)，使
\[
\frac1x\int_0^x f(t)dt=f(\xi).
\]
当 \(x\to0\) 时 \(\xi\to0\)，由连续性，极限为 \(f(0)\)。

### 例 2：有界性夹逼
若 \(|f(t)|\le M\)，求
\[
\lim_{x\to0}\int_0^x f(t)dt.
\]
有
\[
\left|\int_0^x f(t)dt\right|\le M|x|\to0,
\]
故极限为 0。

### 例 3：含连续函数的二阶平均
设 \(f\) 在 0 连续，求
\[
\lim_{x\to0}\frac1{x^2}\int_0^x t f(t)dt.
\]
写成
\[
\frac1{x^2}\int_0^x t f(t)dt
=\frac1{x^2}\left[f(0)\frac{x^2}{2}
+\int_0^x t(f(t)-f(0))dt\right].
\]
余项满足
\[
\left|\frac1{x^2}\int_0^x t(f(t)-f(0))dt\right|
\le \frac12\sup_{t\text{介于}0与x}|f(t)-f(0)|\to0.
\]
因此极限为 \(f(0)/2\)。

## 12. 常见错误与验收

- [ ] 检查被积函数连续或有界的条件。
- [ ] 积分区间长度与分母阶数匹配。
- [ ] 上下限交换时符号正确。
- [ ] 参数变化时，估计在整个积分区间成立。
- [ ] 没有把积分中值定理用于不满足连续条件的情形。
- [ ] 没有在积分区间不收缩时误用区间长度估计得出零极限。
