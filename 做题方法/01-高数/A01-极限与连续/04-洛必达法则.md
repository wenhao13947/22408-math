## 1. 题型定位

洛必达法则是处理特定未定式极限的工具，不是任意极限都能使用的求导口诀。

常见形式为：

\[
\lim_{x\to a}\frac{f(x)}{g(x)}.
\]

若在适当的去心邻域内，\(f,g\) 可导、\(g'(x)\ne0\)，原商为 \(0/0\) 或 \(\infty/\infty\) 型，并且导数之比的极限存在（有限或适当的无穷极限），则可在相应定理条件下得到：

\[
\lim_{x\to a}\frac{f(x)}{g(x)}
=
\lim_{x\to a}\frac{f'(x)}{g'(x)}.
\]

具体使用时，应以教材所采用的洛必达法则完整条件为准，尤其注意单侧趋近、无穷远趋近以及导数比极限存在等要求。

**最重要的边界：洛必达法则直接适用于 \(0/0\) 与 \(\infty/\infty\) 两种型，不直接适用于 \(0\cdot\infty\)、\(\infty-\infty\) 或幂指型。**

## 2. 题型识别：看到什么，想到什么

| 代入或判断结果 | 能否直接用洛必达 | 先做什么 |
|---|---|---|
| \(0/0\) | 在其他条件满足时可以 | 检查可导性与导数比 |
| \(\infty/\infty\) | 在其他条件满足时可以 | 检查导数比 |
| \(0\cdot\infty\) | 不可以直接用 | 改写成商 |
| \(\infty-\infty\) | 不可以直接用 | 通分、有理化或合并成商 |
| \(1^\infty,0^0,\infty^0\) | 不可以直接用 | 设 \(y\)，取对数 |
| 分母导数为零 | 不能据此继续套用 | 检查定理条件，考虑其他方法 |
| 求导后表达式更复杂 | 不必继续 | 回到代数、等价无穷小或泰勒展开 |

## 3. 目标分析

使用洛必达前回答四个问题：

1. 原式是否确实为 \(0/0\) 或 \(\infty/\infty\)？
2. 分子、分母在去心邻域内是否满足可导等条件？
3. 求导后是否更容易求极限？
4. 导数之比的极限是否能够求出？

如果第一个问题答案是否定的，不能直接使用洛必达。若求导后变复杂，也不应为了连续使用该法则而反复求导。

## 4. 条件挖掘

| 条件 | 数学意义 | 操作 |
|---|---|---|
| 分子、分母均趋于 0 | \(0/0\) 型 | 可检查洛必达条件 |
| 分子、分母绝对值均趋于无穷 | \(\infty/\infty\) 型 | 可检查洛必达条件 |
| \(f,g\) 在去心邻域可导 | 导数存在 | 可进一步检查定理 |
| \(g'(x)\ne0\) | 导数商有定义 | 检查导数比 |
| 导数比极限存在 | 可应用相应定理结论 | 得到原商极限 |
| 原式为乘积型 | 尚非洛必达适用形式 | 先改写成商 |
| 原式为差式型 | 尚非洛必达适用形式 | 先通分、有理化或代数合并 |

不能只因为原式“看起来像分式”就使用洛必达；必须先确认未定式类型。

## 5. 知识联想

- 求导法则：使用乘积、商、复合函数求导。
- 等价无穷小：若一眼可得，通常比洛必达更短。
- 泰勒展开：当多次求导导致式子复杂时，可直接找主导项。
- 有理化：根式差经常无需洛必达。
- 幂指极限：先取对数，再判断对数后的商是否为 \(0/0\) 或 \(\infty/\infty\)。

## 6. 路线选择

### 路线 A：直接使用一次洛必达

**触发条件：**原式为合法的 \(0/0\) 或 \(\infty/\infty\) 型，求导后结构明显简化。

步骤：
1. 写出原式的未定式类型；
2. 说明在适用条件下使用洛必达；
3. 分别对分子、分母求导；
4. 求导数之比的极限。

### 路线 B：连续使用洛必达

**触发条件：**求导后仍是 \(0/0\) 或 \(\infty/\infty\)，且每一步仍满足法则条件。

每次求导后都重新检查未定式类型和条件。不能因为第一次合法，就默认第二次、第三次也合法。

### 路线 C：先变形，再使用洛必达

**触发条件：**原式为 \(0\cdot\infty\) 或 \(\infty-\infty\)，且代数变形可以转成商。

例如：

\[
x\ln x=\frac{\ln x}{1/x}\quad(x\to0^+),
\]

转成 \((-\infty)/(\infty)\) 型后，再检查洛必达条件。

### 路线 D：放弃洛必达，改用其他方法

**触发条件：**求导后更复杂，或等价无穷小、泰勒展开、恒等变形更直接。

洛必达是工具，不是必须完成的流程。

## 7. 完整操作流程

1. 直接代入或分析分子、分母的趋近状态。
2. 明确写出 \(0/0\) 或 \(\infty/\infty\)。
3. 检查可导性、分母导数以及趋近区间等条件。
4. 判断求导是否能简化。
5. 对分子和分母分别求导，不能把商整体按错误规则求导。
6. 求新的极限。
7. 若仍为适用未定式，重新检查条件后再决定是否继续。
8. 得出结果，并检查是否存在单侧与双侧差异。

## 8. 方法边界与常见变形

### 8.1 \(0\cdot\infty\) 型

将乘积写成商，例如：

\[
f(x)g(x)=\frac{f(x)}{1/g(x)}
\]

或

\[
f(x)g(x)=\frac{g(x)}{1/f(x)}.
\]

选择能形成清晰 \(0/0\) 或 \(\infty/\infty\) 型的一种。变形后仍要检查定义域与趋近方向。

### 8.2 \(\infty-\infty\) 型

常见处理：
- 通分；
- 根式有理化；
- 提取主导项；
- 化成一个分式后再判断是否适用洛必达。

### 8.3 幂指型

若底数为正，设：

\[
y=f(x)^{g(x)},\qquad
\ln y=g(x)\ln f(x).
\]

先求 \(\ln y\) 的极限，再利用指数函数连续性恢复 \(y\) 的极限。

## 9. 方法切换

| 触发信号 | 不要做什么 | 应切换为 |
|---|---|---|
| 原式不是 \(0/0\) 或 \(\infty/\infty\) | 直接求导 | 先变形或选其他方法 |
| 求导后更复杂 | 盲目连续求导 | 等价无穷小、泰勒或代数变形 |
| 分母导数为零且导数商无定义 | 忽略条件 | 重新判断定理是否适用 |
| 导数比仍为未定式 | 不检查就再次求导 | 重新验证条件 |
| 根式差 | 先复杂求导 | 优先有理化 |
| 多项抵消 | 反复求高阶导数 | 比较泰勒展开成本 |
| 单侧极限不一致 | 写成双侧结果 | 分别计算左右极限 |

## 10. 双版本作答

### 10.1 练习版

1. 原式代入后为……型。
2. 分子、分母在相应去心邻域内满足……
3. 因此可使用洛必达法则。
4. 分子导数为……，分母导数为……
5. 新极限为……
6. 所以原极限为……
7. 若再次使用洛必达，补充检查新表达式仍为适用未定式。

### 10.2 考场版

例如：

\[
\begin{aligned}
\lim_{x\to0}\frac{e^x-1}{x}
&\overset{0/0}{=}
\lim_{x\to0}\frac{e^x}{1}\\
&=1.
\end{aligned}
\]

书写时应让阅卷者看出原式属于 \(0/0\) 型。若题目条件或过程存在特殊情形，应补充适用说明。

### 10.3 最低有效作答

至少写出：
- 原式的未定式类型；
- 分子、分母分别求导后的表达式；
- 导数比的极限。

若原式不是两种适用未定式之一，宁可改用正确变形，也不要硬套洛必达。

## 11. 例题验证

### 例 1：标准题——\(0/0\) 型

求：

\[
\lim_{x\to0}\frac{e^x-1}{x}.
\]

分子、分母均趋于 0。在适用条件下：

\[
\begin{aligned}
\lim_{x\to0}\frac{e^x-1}{x}
&=\lim_{x\to0}\frac{e^x}{1}\\
&=\boxed{1}.
\end{aligned}
\]

### 例 2：变式题——\(\infty/\infty\) 型

求：

\[
\lim_{x\to\infty}\frac{\ln x}{x}.
\]

当 \(x\to\infty\)，分子、分母均趋于无穷。使用洛必达：

\[
\begin{aligned}
\lim_{x\to\infty}\frac{\ln x}{x}
&=\lim_{x\to\infty}\frac{1/x}{1}\\
&=\boxed{0}.
\end{aligned}
\]

### 例 3：综合题——乘积型先化商

求：

\[
\lim_{x\to0^+}x\ln x.
\]

原式为 \(0\cdot(-\infty)\)，不能直接使用洛必达。改写：

\[
x\ln x=\frac{\ln x}{1/x}.
\]

此时分子趋于 \(-\infty\)，分母趋于 \(+\infty\)，为 \(\infty/\infty\) 型（按绝对值趋于无穷）。于是：

\[
\begin{aligned}
\lim_{x\to0^+}\frac{\ln x}{1/x}
&=\lim_{x\to0^+}\frac{1/x}{-1/x^2}\\
&=\lim_{x\to0^+}(-x)\\
&=\boxed{0}.
\end{aligned}
\]

### 例 4：反例提醒——不是未定式不能硬用

求：

\[
\lim_{x\to0}\frac{x^2+1}{x+1}.
\]

直接代入得 \(1\)，不是 \(0/0\) 或 \(\infty/\infty\) 型，不需要也不能以洛必达作为理由。由连续性：

\[
\boxed{1}.
\]

## 12. 常见错误与验收

### 常见错误

1. 不判断未定式就直接求导。
2. 把 \(0\cdot\infty\) 当成洛必达可直接处理的形式。
3. 对 \(\infty-\infty\) 直接分别求导。
4. 对商求导时误把洛必达写成商的求导法则；洛必达是分子、分母分别求导后比较极限。
5. 连续多次使用时不重新检查条件。
6. 求导后更复杂仍机械继续。
7. 忽略单侧趋近和定义域。
8. 把导数比极限不存在时的情形错误地套入简单结论。

### 验收清单

- [ ] 原式属于 \(0/0\) 或 \(\infty/\infty\)；
- [ ] 趋近方向与定义域正确；
- [ ] 分子、分母在所需区间可导；
- [ ] 分母导数条件满足；
- [ ] 每次使用前重新确认未定式；
- [ ] 分子、分母分别求导正确；
- [ ] 导数比极限计算正确；
- [ ] 若求导路线不简洁，已考虑替代方法。

## 考场速查

**洛必达只认两种入口：**

\[
\boxed{\frac00\qquad\frac{\infty}{\infty}}
\]

流程：

1. 先判断未定式；
2. 检查可导等条件；
3. 分子、分母分别求导；
4. 求导后重新判断；
5. 复杂就切回泰勒、等价或代数变形。

**口诀：先看型，再看条件；每求一次导，都重新验一次。**
