# A02｜单调性、极值与最值

> V1.0 初稿｜待验证

## 1. 题型定位
利用一阶导数确定函数增减、局部极值和闭区间最值，并解决参数范围、不等式及方程根问题。

## 2. 题型识别
| 题目 | 关键工具 |
|---|---|
| 单调区间 | \(f'\) 符号 |
| 极值点 | 驻点及不可导点，检查符号变化 |
| 闭区间最值 | 端点与区间内驻点比较 |
| 参数使单调 | 导数恒正/恒负条件 |
| 根的个数 | 单调性与端点值 |

## 3. 目标分析
单调性看导数符号；极值看局部左右变化；最值必须限定区间并比较候选点。驻点不一定是极值点。

## 4. 条件挖掘
- \(f'(x)>0\) 于区间内，函数严格递增。
- \(f'(x)<0\) 于区间内，函数严格递减。
- 极值点若可导，则通常满足 \(f'(x_0)=0\)，但反向不成立。
- 闭区间连续函数必取得最大最小值。
- 最值候选点：端点、区间内驻点及不可导点。

## 5. 知识联想
一阶导数判别法：导数由正变负为极大值，由负变正为极小值；不变号则通常不是极值。

## 6. 路线选择
A 求导列表：求导、解零点、列表判号。  
B 参数讨论：将导数符号条件转为参数不等式。  
C 根数分析：先用单调性确定至多一个根，再用介值定理证明至少一个根。

## 7. 完整流程
1. 确定定义域和目标区间。
2. 求 \(f'(x)\)。
3. 找导数为零点及不可导点。
4. 划分区间并判导数符号。
5. 写单调区间。
6. 检查导数符号是否改变，判局部极值。
7. 求闭区间最值时计算端点和内部候选点函数值。
8. 根数题结合单调性和端点符号。

## 8. 跨知识点连接
与中值定理、凹凸性、方程根、不等式证明相连。

## 9. 方法切换
导数因式分解困难时研究符号等价式；参数使导数零点变化时分情况；闭区间最值不可只看驻点，必须比较端点。

## 10. 双版本作答
练习版：导数、临界点、符号表、结论完整。  
考场版：写出导数及符号区间，明确端点值比较。  
最低有效作答：列出正确的导数和候选点，不把驻点直接等同极值。

## 11. 例题验证
**例1：**\(f(x)=x^3-3x\)。\(f'=3(x^2-1)\)，故在 \(( -\infty,-1)\)、\((1,\infty)\) 递增，在 \((-1,1)\) 递减；\(x=-1\) 极大值 2，\(x=1\) 极小值 -2。

**例2：**\(f(x)=x^2-2x\) 在 \([0,3]\) 上。驻点 \(x=1\)，比较 \(f(0)=0,f(1)=-1,f(3)=3\)，最小值 -1，最大值 3。

**例3：**证明方程 \(x^3+x-1=0\) 至多一个实根。令 \(f=x^3+x-1\)，则 \(f'=3x^2+1>0\)，严格递增，故至多一个根；又 \(f(0)=-1,f(1)=1\)，由介值定理恰有一个根。

## 12. 错误与验收
- [ ] 定义域和区间端点正确。
- [ ] 临界点没有遗漏不可导点。
- [ ] 驻点与极值点没有混淆。
- [ ] 最值题比较端点与内部候选点。
- [ ] 根数结论同时检查至多与至少。
