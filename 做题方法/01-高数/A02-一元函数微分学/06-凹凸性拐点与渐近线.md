# A02｜凹凸性、拐点与渐近线

> V1.0 初稿｜待验证

## 1. 题型定位
用二阶导数研究曲线凹凸性与拐点，并结合极限判断渐近线，完成函数性态分析。

## 2. 题型识别
| 看到 | 工具 |
|---|---|
| 凹凸区间 | 二阶导数符号 |
| 拐点 | 凹凸性改变且函数图像连续经过该点 |
| 水平渐近线 | 无穷远函数极限 |
| 斜渐近线 | 求斜率与截距 |
| 竖直渐近线 | 有限点单侧无穷极限 |

## 3. 目标分析
二阶导数符号用于判断凹凸性（按教材约定说明凹凸方向）；拐点要求凹凸性发生改变，单有 \(f''(x_0)=0\) 不足以判定。渐近线按极限定义判断。

## 4. 条件挖掘
- \(f''>0\) 或 \(f''<0\) 决定相应区间的凹凸方向。
- 拐点处二阶导可能为零，也可能不存在。
- 水平渐近线 \(y=b\)：\(f(x)\to b\)。
- 斜渐近线 \(y=kx+b\)：\(f(x)-(kx+b)\to0\)。
- 竖直渐近线 \(x=a\)：至少一侧函数趋于无穷。

## 5. 知识联想
二阶导数判别、无穷远极限、单侧极限、函数图形综合分析。

## 6. 路线选择
A 二阶导数符号表：求 \(f''\)，找零点和不存在点，分区间判号。  
B 拐点验证：比较候选点左右凹凸性。  
C 渐近线：先水平，再斜，最后检查定义域边界的竖直渐近线。

## 7. 完整流程
1. 求定义域。
2. 求一阶、二阶导数。
3. 找 \(f''=0\) 和 \(f''\) 不存在的点。
4. 分区间判二阶导符号。
5. 找凹凸性改变的点并检查函数连续经过。
6. 求无穷远极限与斜渐近线参数。
7. 检查有限定义域边界的单侧无穷极限。
8. 汇总图形特征。

## 8. 跨知识点连接
与单调极值、无穷远极限、极限存在性和导数定义相连。

## 9. 方法切换
二阶导复杂时先因式分解或符号变形；候选拐点不改变凹凸时排除；渐近线不能仅凭图像猜测，回到极限定义。

## 10. 双版本作答
练习版：列出一阶、二阶导数符号表和各类渐近线极限。  
考场版：保留关键符号区间与极限式。  
最低有效作答：写出正确的二阶导表达式和候选拐点，不将 \(f''=0\) 直接判为拐点。

## 11. 例题验证
**例1：**\(f(x)=x^3\)，\(f''=6x\)，在 0 左右变号，故 \((0,0)\) 为拐点。

**例2：**\(f(x)=x^4\)，\(f''=12x^2\ge0\)，在 0 两侧不变号，故 0 不是拐点。

**例3：**\(f(x)=1/x\)，当 \(x\to0^+\) 趋于 \(+\infty\)，当 \(x\to0^-\) 趋于 \(-\infty\)，故 \(x=0\) 为竖直渐近线；当 \(x\to\pm\infty\)，函数趋于 0，水平渐近线为 \(y=0\)。

## 12. 错误与验收
- [ ] 凹凸方向与二阶导符号一致且遵循统一约定。
- [ ] 拐点检查左右凹凸变化。
- [ ] 渐近线由极限定义确认。
- [ ] 正负无穷分别分析。
