## 1. 题型定位

本模板解决的核心问题不是“如何计算二重积分”，而是：

**当积分区域边界由多段曲线、多个不等式或不同方向的边界共同围成时，如何准确描述区域，并把它拆成能够正确写出积分限的简单区域。**

复杂区域题通常包含两个相互独立的任务：

1. **区域几何任务：** 确认区域在哪里、边界是什么、交点在哪里、是否需要分割。
2. **积分表达任务：** 选择直角坐标或极坐标，确定积分次序，并写出每一块区域的上下限。

不要把这两个任务混在一起。先把区域弄清楚，再写积分。

---

## 2. 题型识别

### 2.1 常见信号

| 题目出现的内容 | 对应的数学结构 | 首要动作 |
|---|---|---|
| 由多个不等式共同确定区域 | 多个条件的交集 | 逐条翻译不等式，画出边界 |
| 区域由几段曲线围成 | 分段边界 | 求交点，判断边界在哪些区间切换 |
| 上边界或下边界中途改变 | 一个方向的截线穿过不同边界 | 考虑按边界切换点分割 |
| 左边界或右边界中途改变 | 另一方向的截线穿过不同边界 | 考虑改变积分次序 |
| 区域呈扇形、圆环扇形或由射线围成 | 极角范围可能简单 | 评估极坐标 |
| 区域关于某条轴或原点对称 | 几何对称 | 调用 J04，先判断能否简化 |

### 2.2 识别流程

看到多个边界，不要立刻写多个积分。先问：

1. 这些边界各自对应什么曲线或直线？
2. 它们的交点在哪里？
3. 沿 \(x\) 方向切一刀，截线是否始终只有一段连续区间？
4. 沿 \(y\) 方向切一刀，情况是否更简单？
5. 换成极坐标后，角度和半径范围是否更简单？

**关键判断：** 若固定一个变量后，另一个变量的取值区间会在中途改变表达式，就说明当前积分次序可能需要分割。

## 3. 目标分析

复杂区域分割的目标，是把原区域 \(D\) 表示成有限个简单区域的并：

\[
D=D_1\cup D_2\cup\cdots\cup D_n
\]

并尽量满足：

- 各子区域内部互不重叠；
- 子区域的并恰好覆盖原区域；
- 每个子区域都能用单组积分限表示；
- 分割边界通常是面积为零的曲线，不影响二重积分的加和。

于是：

\[
\iint_D f(x,y)\,d\sigma
=
\sum_{k=1}^{n}\iint_{D_k}f(x,y)\,d\sigma
\]

其中 \(d\sigma=dx\,dy\)。

注意：分割不是越多越好。优先选择子区域数量少、积分限简单、被积函数容易处理的方案。

## 4. 条件挖掘

### 4.1 把题目条件翻译成几何信息

| 题目条件 | 数学含义 | 需要得到的结果 |
|---|---|---|
| \(g(x,y)\geq 0\) | 区域在曲线 \(g(x,y)=0\) 的一侧 | 判断取哪一侧，可代入测试点 |
| \(a\leq x\leq b\) | 竖直投影范围受限 | 外层 \(x\) 的范围 |
| \(c\leq y\leq d\) | 水平投影范围受限 | 外层 \(y\) 的范围 |
| \(y\leq \varphi(x)\) | 位于曲线下方 | 竖直截线的上界 |
| \(y\geq \psi(x)\) | 位于曲线上方 | 竖直截线的下界 |
| \(x\leq \alpha(y)\) | 位于某条曲线左侧 | 水平截线的右界或左界需结合图形判断 |
| 两条边界相交 | 边界可能发生切换 | 求交点，确定分割位置 |
| \(x^2+y^2\leq R^2\) | 圆盘 | 同时评估直角坐标与极坐标 |

### 4.2 必须求出的关键数据

- 所有可能影响边界切换的交点；
- 区域在 \(x\) 轴、\(y\) 轴上的投影范围；
- 每一段截线的起点和终点；
- 哪些边界是实际边界，哪些只是辅助分割线。

**交点计算后要回到图形检查。** 方程的交点不一定都属于题目区域，必须代回原不等式筛选。

## 5. 知识联想

### 5.1 从边界想到积分限

若区域能写成

\[
D=\{(x,y)\mid a\leq x\leq b,\ \varphi_1(x)\leq y\leq\varphi_2(x)\},
\]

则是沿竖直方向描述区域：

\[
\iint_D f(x,y)\,dx\,dy
=
\int_a^b\left[\int_{\varphi_1(x)}^{\varphi_2(x)}
f(x,y)\,dy\right]dx.
\]

若区域能写成

\[
D=\{(x,y)\mid c\leq y\leq d,\ \psi_1(y)\leq x\leq\psi_2(y)\},
\]

则是沿水平方向描述区域：

\[
\iint_D f(x,y)\,dx\,dy
=
\int_c^d\left[\int_{\psi_1(y)}^{\psi_2(y)}
f(x,y)\,dx\right]dy.
\]

### 5.2 从“边界切换”想到分割

例如竖直截线下的上边界为

\[
y=
\begin{cases}
\varphi_1(x),&a\leq x\leq m,\\
\varphi_2(x),&m\leq x\leq b,
\end{cases}
\]

那么应在 \(x=m\) 处分割，写成两个积分。

但如果改用水平截线后，左右边界能由一组公式统一描述，就可能不必分割。**分割与改变积分次序是两种可比较的表达方式，不要把分割当成唯一选择。**

### 5.3 从圆形边界想到极坐标

若边界大量出现 \(x^2+y^2\)、圆弧或射线，调用 J03。判断重点不是“有没有圆”，而是极坐标能否同时简化区域和被积函数。

## 6. 路线选择

### 路线 A：直角坐标，沿竖直方向分割

**触发条件：**
- \(x\) 的总范围容易确定；
- 固定 \(x\) 后，区域是若干段 \(y\) 区间；
- 上下边界在某些 \(x\) 值处发生切换。

**操作：**
1. 求交点并确定 \(x\) 的分段点；
2. 对每一段确定下边界和上边界；
3. 每一段分别写成 \(dy\,dx\)；
4. 将各部分积分相加。

**优点：** 边界若本来就是 \(y=f(x)\)，表达直接。

**风险：** 容易漏掉边界切换点，或把上、下边界写反。

### 路线 B：直角坐标，改变次序后沿水平方向描述

**触发条件：**
- 竖直截线会多次切换；
- 水平截线能一次穿过区域；
- 反解边界方程后，左右边界较简单。

**操作：**
1. 先求区域的 \(y\) 总范围；
2. 固定 \(y\)，确定最左和最右的 \(x\)；
3. 检查左右边界是否仍会切换；
4. 若不切换，写成一个积分；若切换，则按切换点分割。

**优点：** 可以减少积分块数。

**风险：** 反解曲线时容易选错分支。例如 \(y=x^2\) 反解为 \(x=\pm\sqrt y\)，必须根据区域所在象限选取分支。

### 路线 C：极坐标描述后积分

**触发条件：**
- 区域主要由圆弧、圆盘、射线或 \(x^2+y^2\) 型边界构成；
- 用极坐标后角度范围与径向范围更规则。

**操作：**
1. 令 \(x=r\cos\theta,\ y=r\sin\theta\)；
2. 把每条边界改写为 \(r,\theta\) 的关系；
3. 确定角度范围；
4. 固定角度，判断 \(r\) 的起止范围；
5. 加入 Jacobian 因子 \(r\)。

\[
dx\,dy=r\,dr\,d\theta.
\]

**风险：** 不能遗漏 \(r\)，也不能把角度范围与半径范围混淆。

### 路线比较原则

按以下优先级比较：

1. 是否完整覆盖原区域且没有重复；
2. 积分限是否容易准确写出；
3. 被积函数是否容易积分；
4. 积分块数是否少；
5. 是否需要复杂反函数或繁琐三角代换。

不要只追求积分个数最少。有时多一个简单积分，比一个边界复杂、容易写错的积分更稳妥。

## 7. 完整操作流程

### 第一步：把每条边界单独写出来

把不等式转成等式边界，并标注不等式方向。例如：

\[
y\geq 0,\qquad y\leq x,\qquad y\leq 2-x.
\]

### 第二步：求边界交点

联立相关边界方程，求出交点。将交点代回原条件，排除不属于区域的解。

### 第三步：确定区域所在位置

至少确认：
- \(x\) 的最小值与最大值；
- \(y\) 的最小值与最大值；
- 区域是否跨越坐标轴；
- 是否存在孔洞或多个不连通部分。

### 第四步：选择截线方向

想象一条竖直线在区域内移动，再想象一条水平线移动。比较哪种方向下截线的边界变化更少。

### 第五步：找出分割点

若截线上界、下界、左界或右界发生变化，求出变化发生的位置。该位置通常来自边界曲线交点或投影端点。

### 第六步：逐块写积分限

每一块都单独检查：
- 外层变量范围是否正确；
- 内层下限是否小于上限；
- 内层上下限是否对应真实边界；
- 该块是否与其他块重叠。

### 第七步：检查并集

把各块放回原图，检查是否有遗漏、重叠或多算。

### 第八步：再做积分计算

区域表达确认正确后，才调用 J01 的计算方法；若发现次序不利于计算，返回路线选择阶段比较 J02 或 J03。

## 9. 方法切换

| 当前方法 | 出现的问题 | 切换方向 |
|---|---|---|
| 竖直分割 | 上下边界切换次数很多 | 尝试水平截线，调用 J02 |
| 水平描述 | 左右边界反解困难或分支多 | 返回竖直分割 |
| 直角坐标 | 圆弧导致根式积分限复杂 | 尝试极坐标 J03 |
| 极坐标 | 角度范围或径向边界反而复杂 | 返回直角坐标 |
| 多块分割 | 发现各块可由对称变换对应 | 调用 J04 检查是否可合并或折半 |

**切换原则：** 只要当前表示方式无法用清楚、无歧义的积分限描述区域，就应退回几何图形重新选择；不要为了坚持某种方法而制造更多分段。

## 10. 双版本作答

### 10.1 练习版：完整思考过程

练习时按以下顺序写在草稿上：

1. 写出所有边界方程和不等式；
2. 求交点并标注坐标；
3. 画出区域草图，标记实际边界；
4. 分别尝试竖直截线和水平截线；
5. 比较分割数量与边界表达难度；
6. 选定一种表示方式；
7. 写出每个子区域的集合表达；
8. 写出积分和式；
9. 检查并集、交集和积分限；
10. 最后计算并验算。

练习阶段必须说清楚“为什么在这里分割”，而不能只记住某道题的分割点。

### 10.2 考场版：规范书写

可使用以下表达：

“由区域边界方程联立，得交点……。沿 \(x\) 方向观察，区域上（下）边界在 \(x=\cdots\) 处发生变化，因此将区域分为 \(D_1,D_2\)。于是”

\[
\iint_D f(x,y)\,dx\,dy
=
\iint_{D_1}f(x,y)\,dx\,dy+
\iint_{D_2}f(x,y)\,dx\,dy.
\]

随后分别写出积分限并计算。

若改变积分次序更简单，则说明“改沿水平方向描述区域”，再给出新的积分限。考场上不必写冗长的尝试过程，但必须保证积分限有依据。

### 10.3 最低有效作答

当暂时无法完成计算时，尽量保留确定正确的步骤：

1. 写出真实边界方程；
2. 求出能够确认的交点；
3. 写出正确的区域范围或部分子区域；
4. 写出已确认无误的积分表达式。

不要猜测剩余积分限。错误的完整积分式可能比正确的部分表达更危险。

## 11. 例题验证

### 例 1：上边界中途改变——必须分割或改变次序

设区域

\[
D=\{(x,y)\mid 0\leq x\leq 2,\ 0\leq y\leq \min(x,2-x)\}.
\]

求区域面积：

\[
I=\iint_D 1\,dx\,dy.
\]

**分析：**

上边界是两条直线 \(y=x\) 与 \(y=2-x\) 中较小的一条。令两者相等：

\[
x=2-x\quad\Longrightarrow\quad x=1.
\]

因此沿竖直方向必须在 \(x=1\) 处分段。

**路线 A：竖直分割**

\[
D_1:\ 0\leq x\leq1,\quad 0\leq y\leq x,
\]

\[
D_2:\ 1\leq x\leq2,\quad 0\leq y\leq2-x.
\]

于是

\[
\begin{aligned}
I
&=\int_0^1\int_0^x1\,dy\,dx
+\int_1^2\int_0^{2-x}1\,dy\,dx\\
&=\int_0^1x\,dx+\int_1^2(2-x)\,dx\\
&=\frac12+\frac12=1.
\end{aligned}
\]

**路线 B：改变积分次序**

从水平截线观察，\(y\) 从 \(0\) 到 \(1\)。固定 \(y\) 后，左边界来自 \(y=x\)，即 \(x=y\)；右边界来自 \(y=2-x\)，即 \(x=2-y\)。

因此

\[
D=\{(x,y)\mid 0\leq y\leq1,\ y\leq x\leq2-y\}.
\]

于是

\[
\begin{aligned}
I
&=\int_0^1\int_y^{2-y}1\,dx\,dy\\
&=\int_0^1(2-2y)\,dy\\
&=1.
\end{aligned}
\]

**结论：** 两种写法都正确。竖直方向需要分成两块；水平方向只需一个积分。考试中优先选择自己最不容易写错的表达。

### 例 2：区域由曲线围成——交点决定积分范围

设区域由

\[
y=x^2,\qquad y=2x
\]

围成，求其面积。

**第一步：求交点**

\[
x^2=2x
\quad\Longrightarrow\quad
x(x-2)=0,
\]

所以交点为 \((0,0)\) 与 \((2,4)\)。

**第二步：判断上下边界**

在 \(0\leq x\leq2\) 内，\(2x\geq x^2\)，所以直线是上边界，抛物线是下边界。

**第三步：建立积分**

\[
\begin{aligned}
S
&=\int_0^2(2x-x^2)\,dx\\
&=\left[x^2-\frac{x^3}{3}\right]_0^2\\
&=4-\frac83=\frac43.
\end{aligned}
\]

这里无需分割，因为竖直截线始终从抛物线穿到直线。**边界有两条曲线，不等于一定要分割。**

### 例 3：综合判断——先检查对称性，再选区域表达

设

\[
D=\{(x,y)\mid 0\leq x\leq2,\ 0\leq y\leq\min(x,2-x)\},
\]

求

\[
I=\iint_D(x-1)\,dx\,dy.
\]

**第一步：识别几何结构**

区域关于直线 \(x=1\) 对称。被积函数 \(x-1\) 关于该直线变号：

\[
(1+u)-1=u,\qquad (1-u)-1=-u.
\]

**第二步：利用对称性**

将变换写为

\[
T(x,y)=(2-x,y).
\]

该变换保持区域不变，Jacobian 的绝对值为 \(1\)，且

\[
f(2-x,y)=(2-x)-1=-(x-1)=-f(x,y).
\]

因此

\[
\boxed{I=0}.
\]

**第三步：如果没有识别对称性**

可以使用例 1 的竖直分割：

\[
I=
\int_0^1\int_0^x(x-1)\,dy\,dx
+
\int_1^2\int_0^{2-x}(x-1)\,dy\,dx.
\]

这两部分互为相反数，结果仍为 \(0\)。

**结论：** 区域分割不只是为了写积分限。先识别对称性，有时可以直接避免繁琐计算。此处调用 J04。

## 12. 常见错误与验收

### 12.1 常见错误

1. **只求交点，不检查原不等式。**  
   纠正：交点必须代回区域条件，确认属于边界范围。

2. **看到两条曲线就分割。**  
   纠正：先看固定一个变量后，上下边界是否发生切换。例 2 不需要分割。

3. **分割点取错。**  
   纠正：分割点应来自真实边界切换或投影端点，而不是随意选取。

4. **改变积分次序时直接交换积分符号。**  
   纠正：必须重新描述区域，重新求外层范围和内层左右边界。

5. **反解曲线时选错分支。**  
   纠正：例如 \(y=x^2\) 对应 \(x=\pm\sqrt y\)，要结合区域位置选分支。

6. **分割后漏算或重复计算。**  
   纠正：把所有子区域重新画回原图，检查覆盖关系。

7. **把边界曲线当成有面积的重叠部分。**  
   纠正：有限条正常曲线边界的面积为零，分割时边界重复本身不影响二重积分；但不能让子区域内部重叠。

8. **先计算，后检查区域。**  
   纠正：积分限错误时，后续计算再熟练也无法得到正确答案。

## 考场速查：复杂区域分割

**看到多条边界 → 先求交点 → 画区域 → 试竖直/水平截线 → 找边界切换点 → 决定分割或换序 → 检查覆盖 → 再积分。**

| 检查问题 | 快速判断 |
|---|---|
| 上下边界是否变化？ | 变化则考虑竖直分割 |
| 左右边界是否变化？ | 变化则考虑水平分割 |
| 哪个方向分段少？ | 优先考虑哪个方向 |
| 圆弧、射线是否主导区域？ | 试极坐标 |
| 区域与函数是否有对称性？ | 调用 J04 |
| 积分限是否不确定？ | 暂停计算，回到图形分析 |

**最后提醒：复杂区域题最重要的不是算得快，而是先把区域表达正确。**
