# J06｜二重积分综合题：识别、选路与完整求解

> 版本：V1.0  
> 状态：初稿；J01—J06 尚需统一真题与变式验收  
> 定位：本文件不是新的单一计算技巧，而是把区域、积分次序、极坐标、对称性和分割方法组合成可执行的综合决策流程。

---

## 1. 题型定位

综合题通常同时包含两个或多个任务：

- 从不等式、曲线或文字条件识别积分区域；
- 判断直角坐标或极坐标；
- 选择积分次序，必要时改变次序；
- 利用对称性化简；
- 对复杂区域分割；
- 完成积分计算并检查结果。

核心流程：

\[
\boxed{\text{先看区域与函数，再选坐标与路线，最后计算并验收}}
\]

不要一看到二重积分就立刻写积分限。积分限是区域分析的结果，不是解题的起点。

## 2. 题型识别：看到什么，想到什么

| 题目特征 | 可能的数学结构 | 首要检查 |
|---|---|---|
| \(x,y\) 分别被常数或简单曲线约束 | 直角坐标简单区域 | J01 |
| 原积分的内层积分难以计算 | 积分次序不合适 | J02 |
| \(x^2+y^2\)、圆盘、扇形、射线边界 | 径向结构 | J03 |
| 区域关于坐标轴、原点或 \(y=x\) 对称 | 对称区域 | J04 |
| 同方向切片断开、边界多次切换 | 复杂区域 | J05 |
| 同时出现圆弧、直线、奇偶性或分段边界 | 多方法组合 | 先综合判断，不机械套单一模板 |

## 3. 目标分析

开始计算前，明确四个目标：

1. **区域目标：**准确确定 \(D\)，包括所有边界和范围。
2. **简化目标：**检查对称性，避免不必要的重复计算。
3. **表达目标：**选择能用最少且最清晰的积分描述区域的方法。
4. **计算目标：**让被积函数和积分区域在所选坐标下尽量简单。

综合题的最优路线不一定是最少积分号，而是总错误风险和运算负担较低的路线。

## 4. 条件挖掘

把条件分成四组：

| 条件组 | 常见信息 | 转化结果 |
|---|---|---|
| 区域边界 | 直线、抛物线、圆、椭圆、坐标轴 | 边界方程与交点 |
| 区域范围 | 不等式、象限、\(x,y\) 正负限制 | 投影范围与角度范围 |
| 被积函数 | 奇偶性、径向函数、乘积、和式 | 可用坐标、对称性或分离积分 |
| 题目要求 | 计算、换序、证明、求参数 | 决定必须展示的步骤 |

### 条件转化示例

- \(x^2+y^2\le R^2\)：圆盘，极坐标中 \(0\le r\le R\)。
- \(y\ge0\)：上半平面，极坐标角度需满足 \(\sin\theta\ge0\)。
- \(x\ge0,y\ge0\)：第一象限，\(0\le\theta\le\pi/2\)。
- \(f(-x,y)=-f(x,y)\)：函数关于 \(x\) 为奇对称；只有区域关于 \(y\) 轴对称时，才能据此判断积分为零。
- \(f(x,y)=g(x^2+y^2)\)：被积函数只依赖半径，极坐标通常值得优先检查。

## 5. 知识联想

综合题按以下顺序联想：

1. **对称性（J04）：**如果成立，先化简。
2. **坐标选择（J01/J03）：**看边界与被积函数，决定直角或极坐标。
3. **积分次序（J02）：**直角坐标下比较竖直与水平切片。
4. **区域分割（J05）：**当单一描述无法覆盖全区域时使用。
5. **定积分计算：**最后才处理具体原函数、换元和上下限代入。

注意：对称性判断不能只看函数，也不能只看区域；两者必须匹配。

## 6. 路线选择：综合决策树

### 第 1 问：能否直接利用对称性？

检查区域在变换下是否保持不变，以及被积函数如何变化。

- 区域不变、函数变号：对应积分为零。
- 区域不变、函数不变：可将对称部分积分合并。
- 区域或函数不满足条件：不能使用该结论，进入下一步。

### 第 2 问：极坐标是否明显简化？

优先检查：

- 边界是否含 \(x^2+y^2=R^2\)；
- 区域是否由圆弧和过原点的射线围成；
- 被积函数是否含 \(x^2+y^2\) 或仅依赖 \(r\)。

若区域与函数都简化，选 J03。若只有一个方面简化、另一个方面显著变复杂，应比较实际积分难度。

极坐标公式：

\[
x=r\cos\theta,\quad y=r\sin\theta,\quad
\mathrm d\sigma=r\,\mathrm dr\,\mathrm d\theta.
\]

### 第 3 问：直角坐标能否一次描述？

- 竖直切片连续且上下界简单：J01，采用 \(\mathrm dy\,\mathrm dx\)。
- 水平切片连续且左右界简单：J01，采用 \(\mathrm dx\,\mathrm dy\)。
- 一种方向复杂、另一种简单：J02，改变积分次序。
- 两个方向都出现边界切换：J05，分割区域。

### 第 4 问：是否需要组合路线？

例如：

- 先用 J04 将积分化简，再用 J03 计算；
- 先用 J02 换序，再按 J05 分段；
- 先用 J05 分割区域，再对其中圆形部分使用 J03。

**总原则：先化简，再建限；先选路线，再动笔计算。**

## 7. 完整操作流程

### 第一步：读题并标注所有条件

圈出边界方程、范围限制、被积函数结构和题目要求。

### 第二步：画区域草图

求边界交点，标注象限、坐标轴截距、圆心和半径等必要信息。对复杂区域，画图后仍要用不等式验证。

### 第三步：检查对称性

依次考虑关于 \(x\) 轴、\(y\) 轴、原点或 \(y=x\) 的变换。只在区域保持不变时使用奇偶性结论。

### 第四步：比较坐标系

直角坐标：边界是否容易写成 \(y=f(x)\) 或 \(x=g(y)\)？

极坐标：边界是否容易写成 \(r=r(\theta)\)，角度范围是否简单？

### 第五步：比较积分次序与分割

估计每种方案的积分段数、积分限复杂度、内层原函数难度。选择总步骤清楚且不易错的方案。

### 第六步：写出积分表达式

直角坐标：

\[
\iint_D f(x,y)\,\mathrm d\sigma
=\int_a^b\int_{\varphi_1(x)}^{\varphi_2(x)}
f(x,y)\,\mathrm dy\,\mathrm dx.
\]

极坐标：

\[
\iint_D f(x,y)\,\mathrm d\sigma
=\int_{\alpha}^{\beta}
\int_{r_1(\theta)}^{r_2(\theta)}
f(r\cos\theta,r\sin\theta)\,r\,\mathrm dr\,\mathrm d\theta.
\]

### 第七步：计算并检查

逐段完成内层积分，再做外层积分；分割区域时将各部分结果相加。

检查雅可比因子 \(r\)、积分上下限、角度范围、符号和结果量级。

## 8. 跨知识点连接

| 连接 | 何时调用 | 解决什么问题 |
|---|---|---|
| J01 直角坐标 | 区域边界可直接写成上下或左右函数 | 建立累次积分 |
| J02 改变次序 | 当前内层积分困难或切片不合适 | 改用更简单方向描述区域 |
| J03 极坐标 | 圆、扇形、径向函数突出 | 简化边界或被积函数 |
| J04 对称性 | 区域在某种变换下不变 | 判断为零或合并相等部分 |
| J05 复杂区域分割 | 单一切片描述需要多次切换 | 拆成若干简单区域 |

## 9. 方法切换与停止条件

| 发现的问题 | 处理方式 |
|---|---|
| 对称性前提不完整 | 停止使用对称结论，回到区域变换检查 |
| 极坐标角度范围难确定 | 先画射线和边界，若仍复杂则比较直角坐标 |
| 极坐标径向上限多次切换 | 分角度区间，或改用直角坐标 |
| 直角坐标切片断开 | 改变次序或分割区域 |
| 换序后积分限更复杂 | 放弃换序，比较原次序或极坐标 |
| 分割后子区域仍复杂 | 继续细分，或对子区域使用不同坐标 |
| 计算量大但结构简单 | 重新检查对称性、奇偶性和可分离性 |

**停止条件：**当区域被完整、无重无漏地覆盖，积分表达式正确，且计算路线可执行时，停止继续寻找形式上的“更漂亮”方案。

## 10. 双版本作答

### 练习版：完整思考记录

1. 题目给定的区域条件是……
2. 边界交点为……
3. 区域草图显示……
4. 检查对称性：区域在……变换下保持不变；被积函数满足……
5. 比较直角坐标与极坐标，选择……，理由是……
6. 若需要分割，子区域为……
7. 因此积分写成……
8. 计算内层积分……
9. 计算外层积分……
10. 用符号、面积或另一表达式检查结果。

### 考场版：精简但保留依据

先写清区域：

\[
D=\{\text{由题目条件确定的点集}\}.
\]

指出选择方法的理由，例如“区域为圆盘且被积函数只含 \(x^2+y^2\)，故采用极坐标”。然后写出完整积分限与计算过程。

不得只写“利用对称性”“改用极坐标”而不说明适用条件和变量范围。

### 最低有效作答

无法完成全部计算时，优先写出：

1. 正确区域或边界交点；
2. 正确的对称性判断（若条件确实满足）；
3. 正确坐标变换及雅可比，或正确累次积分限；
4. 能可靠完成的中间积分。

宁可保留正确的部分表达式，也不要写不确定的积分限或遗漏极坐标中的 \(r\)。

## 11. 例题验证

### 例 1：对称性 + 极坐标

计算单位圆盘

\[
D=\{(x,y)\mid x^2+y^2\le1\}
\]

上的积分：

\[
I=\iint_D(1+x+y)\,\mathrm d\sigma.
\]

**先检查对称性：**圆盘关于 \(y\) 轴、\(x\) 轴均对称。\(x\) 与 \(y\) 在圆盘上的积分均为零，因此：

\[
I=\iint_D1\,\mathrm d\sigma.
\]

圆盘面积为 \(\pi\)，所以：

\[
\boxed{I=\pi}.
\]

也可用极坐标核对：

\[
I=\int_0^{2\pi}\int_0^1 r\,\mathrm dr\,\mathrm d\theta=\pi.
\]

### 例 2：直角坐标 + 改变积分次序

计算：

\[
I=\int_0^1\int_{x^2}^{x}x\,\mathrm dy\,\mathrm dx.
\]

原区域为：

\[
D=\{(x,y)\mid0\le x\le1,\ x^2\le y\le x\}.
\]

换序后：

\[
D=\{(x,y)\mid0\le y\le1,\ y\le x\le\sqrt y\}.
\]

于是：

\[
\begin{aligned}
I
&=\int_0^1\int_y^{\sqrt y}x\,\mathrm dx\,\mathrm dy\\
&=\frac12\int_0^1(y-y^2)\,\mathrm dy\\
&=\boxed{\frac1{12}}.
\end{aligned}
\]

### 例 3：分割区域 + 直角坐标

设

\[
D=\{(x,y)\mid 0\le x\le1,\ 0\le y\le 2-x\},
\]

计算：

\[
I=\iint_D y\,\mathrm d\sigma.
\]

按水平切片，区域需要在 \(y=1\) 处分段：

\[
I=
\int_0^1\int_0^1 y\,\mathrm dx\,\mathrm dy
+\int_1^2\int_0^{2-y}y\,\mathrm dx\,\mathrm dy.
\]

计算：

\[
\begin{aligned}
I
&=\int_0^1 y\,\mathrm dy+\int_1^2y(2-y)\,\mathrm dy\\
&=\frac12+\left[y^2-\frac{y^3}{3}\right]_1^2\\
&=\frac12+\frac23\\
&=\boxed{\frac76}.
\end{aligned}
\]

用竖直切片核对：

\[
\begin{aligned}
I
&=\int_0^1\int_0^{2-x}y\,\mathrm dy\,\mathrm dx\\
&=\frac12\int_0^1(2-x)^2\,\mathrm dx\\
&=\frac12\left(4-2+\frac13\right)
=\frac76.
\end{aligned}
\]

两种表达结果一致。

## 12. 常见错误与验收

### 常见错误

1. 只看被积函数奇偶性，不检查区域是否对称。
2. 把原点对称误认为关于坐标轴对称。
3. 使用极坐标却遗漏面积元素中的 \(r\)。
4. 角度范围没有结合区域所在象限确定。
5. 换序时只交换积分号，没有重新推导积分限。
6. 区域切片断开，却强行使用单段积分。
7. 分割区域时出现重叠或遗漏。
8. 为了使用熟悉的方法，忽略了更简单的路线。
9. 积分表达式正确，却在内层积分时把外层变量误当成积分变量。

### 验收清单

- [ ] 区域由原始条件准确确定；
- [ ] 边界交点和投影范围正确；
- [ ] 对称性同时检查区域与函数；
- [ ] 直角坐标或极坐标的选择有明确理由；
- [ ] 极坐标的角度、半径范围及 \(r\) 因子正确；
- [ ] 改变积分次序时重新建立了积分限；
- [ ] 分割区域无重无漏；
- [ ] 每段积分的变量、上下限一致；
- [ ] 计算结果经过独立核验；
- [ ] 方法切换理由清楚，未机械套用模板。

## 考场速查：二重积分总决策流程

\[
\boxed{
\text{区域}
\rightarrow
\text{对称性}
\rightarrow
\text{坐标}
\rightarrow
\text{切片/分割}
\rightarrow
\text{计算}
\rightarrow
\text{检查}
}
\]

| 顺序 | 必问问题 | 对应方法 |
|---|---|---|
| 1 | 区域由哪些边界围成？ | 画图、求交点 |
| 2 | 区域和函数是否满足同一对称条件？ | J04 |
| 3 | 圆形或径向结构是否明显？ | J03 |
| 4 | 直角坐标哪种切片更简单？ | J01 |
| 5 | 另一积分次序是否更简单？ | J02 |
| 6 | 是否需要分段才能覆盖全区域？ | J05 |
| 7 | 积分限、雅可比和结果是否正确？ | 验收清单 |

**最后记住：**二重积分综合题的核心能力不是记住更多技巧，而是根据区域和被积函数判断哪一种工具真正适用。
