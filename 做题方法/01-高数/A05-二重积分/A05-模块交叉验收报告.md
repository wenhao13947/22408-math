## 三、需要统一的细节

### P1｜区域描述和积分限

1. **简单区域的定义要统一。** x-型区域固定 \(x\)，y 在一个连续区间内；y-型区域固定 \(y\)，x 在一个连续区间内。若切片断开，必须分割或换序。
2. **换序不是交换积分符号。** J02 已明确要求先恢复区域不等式，再求新投影和左右边界；这一规则应在 J06/A07 中保持一致。
3. **反解边界要结合原区域选分支。** 例如 \(y=x^2\) 反解为 \(x=\pm\sqrt y\)，只有原区域约束 \(x\ge0\) 时才能取正根。
4. **分割区域要检查并集。** 子区域内部互不重叠，合起来恰好覆盖原区域；公共边界的重复不影响二重积分，但不能出现内部重叠。
5. **极坐标半径不必从 0 开始。** 区域不包含原点时，允许 \(r_1(\theta)\le r\le r_2(\theta)\)；不能机械写成 \(0\le r\le R\)。

### P1｜极坐标条件

1. \(d\sigma=r\,dr\,d\theta\)，雅可比因子 \(r\) 不可遗漏。
2. 角度范围必须结合象限和区域确定，不能仅由 \(\tan\theta\) 的值决定。
3. 对 \(r^2\le ar\cos\theta\) 等关系，约去 \(r\) 时应注意 \(r=0\) 的边界点及右侧非负条件；区域描述要完整。
4. 若径向边界随角度切换，应求切换角并分段。
5. 只有当极坐标使区域、被积函数或二者整体简化时才选择；圆方程出现并不自动意味着极坐标最优。

### P2｜交叉内容与重复

1. **J01/J02：**J01 负责建立直角坐标积分；J02 负责将同一区域改用另一方向切片。两份可保留同一典型区域作为前后对照，但不要重复大段定义。
2. **J05/J06：**J05 负责区域分割的完整几何流程；J06 负责在综合题中判断是否调用 J05。
3. **J04/J06：**J04 负责对称性定理与条件；J06 只展示先对称化简、再选择坐标的综合策略。
4. **A07：**是模块总导航与验收表，不应把“待逐题复核”改成“全部通过”，除非已有逐题记录。
