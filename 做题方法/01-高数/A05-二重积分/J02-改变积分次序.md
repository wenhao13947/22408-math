# J02｜二重积分改变积分次序

> 版本：V1.0  
> 状态：初稿，待与 J01、J05、J06 进行模块级综合验证  
> 核心目标：把同一个区域从一种切片描述改写为另一种切片描述；区域不变，只改变积分次序与积分限。

---

## 1. 题型定位

改变积分次序，是把

\[
\int_a^b\int_{\varphi_1(x)}^{\varphi_2(x)}
f(x,y)\,\mathrm dy\,\mathrm dx
\]

改写为

\[
\int_c^d\int_{\psi_1(y)}^{\psi_2(y)}
f(x,y)\,\mathrm dx\,\mathrm dy,
\]

或反向改写。

**本质：**原积分和新积分描述的是同一个平面区域 \(D\)，不是对积分式随意交换两个积分号。

对连续函数在有界区域上的常见考研题，通常可直接使用累次积分与 Fubini 定理；实际做题最关键的是确认区域和积分限。

## 2. 题型识别

| 题目出现的情况 | 数学结构 | 应想到 |
|---|---|---|
| 题目明确要求“交换积分次序” | 同一区域的另一种描述 | 先还原区域，再重新切片 |
| 内层积分无法求原函数或非常复杂 | 当前积分次序不利于计算 | 观察另一方向是否简单 |
| 内层积分上下限含有根式、复杂函数 | 边界函数可能反解后更简单 | 尝试把边界方程解成 \(x=x(y)\) |
| 竖直切片穿过区域的多个分离部分 | 当前方向不是简单区域 | 改成水平切片，或分割 |
| 积分限是常数与曲线混合 | 区域由直线、曲线围成 | 画图并标注交点 |
| 被积函数含 \(e^{x^2}\)、\(\sin(x^2)\) 等难以对 \(x\) 积分的结构 | 当前内层积分可能无法初等计算 | 若换序后 \(x\) 成为外层变量，评估是否改善 |

## 3. 目标分析

改变次序要完成四件事：

1. 从原积分限准确还原区域 \(D\)；
2. 求区域在新外层变量轴上的投影范围；
3. 固定新外层变量，确定新内层变量的左右边界；
4. 检查新积分覆盖区域恰好一次，没有遗漏或重复。

**不能做的事：**仅把 \(\mathrm dy\,\mathrm dx\) 改成 \(\mathrm dx\,\mathrm dy\)，却保留原来的上下限。

## 4. 条件挖掘

原式若为：

\[
\int_a^b\int_{\varphi_1(x)}^{\varphi_2(x)}
f(x,y)\,\mathrm dy\,\mathrm dx,
\]

则它给出：

\[
a\le x\le b,\qquad
\varphi_1(x)\le y\le\varphi_2(x).
\]

将这些不等式作为一个整体，重新描述为：

\[
c\le y\le d,\qquad
\psi_1(y)\le x\le\psi_2(y).
\]

| 原积分信息 | 数学含义 | 改写时的用途 |
|---|---|---|
| \(a\le x\le b\) | 区域的竖直投影范围 | 与曲线共同确定新区域边界 |
| \(\varphi_1(x)\le y\le\varphi_2(x)\) | 固定 \(x\) 时的上下边界 | 画出区域并判断左右边界 |
| \(\varphi_i(x)=y\) | 边界曲线方程 | 反解为 \(x=\psi_i(y)\) |
| 曲线交点 | 边界顺序可能改变 | 决定新积分是否需要分段 |
| 新方向切片断开 | 不是单个简单区域 | 拆分成若干积分 |

### 必查三项

- **交点：**求边界曲线相交的位置。
- **投影：**确定新外层变量的最小值和最大值。
- **边界顺序：**固定新外层变量，判断哪条曲线在左、哪条在右。

## 5. 知识联想

- J01：直角坐标下建立积分限，是本模板的基础。
- J05：换序后若仍出现断开的切片，需要分割区域。
- 定积分换元：反解边界方程只是改变区域描述，不是对积分变量直接做换元。
- Fubini 定理：在适当可积条件下，可以用不同次序的累次积分计算同一个二重积分。
- 几何面积：当被积函数为 \(1\) 时，可用区域面积核对积分结果。

## 6. 路线选择

### 路线 A：直接反解边界，整体换序

适用：区域换成另一方向后仍是简单区域，且边界方程容易反解。

步骤：

1. 写出原区域不等式；
2. 将边界方程反解；
3. 求新外层变量范围；
4. 确定新内层变量的左右边界；
5. 写出新积分。

### 路线 B：换序后分段

适用：新方向的切片连续性只在部分范围内成立，或左右边界发生切换。

步骤：

1. 画出区域并找边界交点；
2. 找到切片结构发生变化的临界值；
3. 将外层变量范围分成若干区间；
4. 每个区间单独确定左右边界；
5. 将各段积分相加。

### 路线 C：不换序，改用其他方法

适用：换序后积分限更复杂、分段更多，或者内层积分本来就容易计算。

可比较 J03 极坐标、J04 对称性、J05 区域分割。题目要求必须换序时，则仍需给出等价的新积分表达式。

**路线选择原则：**改变次序的目标是降低总难度，不是为了形式变化而变化。

## 7. 完整操作流程

### 第一步：把原积分翻译成区域不等式

例如：

\[
\int_0^1\int_{x^2}^{x}f(x,y)\,\mathrm dy\,\mathrm dx
\]

等价于：

\[
0\le x\le1,\qquad x^2\le y\le x.
\]

### 第二步：画区域并标出边界

标出 \(y=x^2\)、\(y=x\) 和交点。必要时用测试点确认区域所在位置。

### 第三步：改用新外层变量描述投影

从图形观察 \(y\) 的取值范围，再通过边界方程确认端点。

### 第四步：把边界解成新内层变量的函数

例如：

\[
y=x^2\Longrightarrow x=\sqrt y
\]

这里取正根是因为原区域还满足 \(0\le x\le1\)，不能无条件省略另一根；若区域包含负 \(x\)，必须重新判断。

### 第五步：固定新外层变量，确认左右边界

沿水平线从左向右穿过区域，写出 \(x\) 的范围。

### 第六步：检查是否需要分段

若左右边界在某个 \(y\) 值处切换，必须分段；若水平切片断开，则考虑进一步拆分区域。

### 第七步：写新积分并核对

检查新旧积分的区域是否相同。若方便，可选择 \(f(x,y)=1\) 比较区域面积，作为辅助核验，但这不能替代对积分限的严格判断。

| 原积分区域描述不清 | J01 | 先掌握原始区域的上下边界 |

## 9. 方法切换

| 触发信号 | 风险 | 处理 |
|---|---|---|
| 新方向切片断成两段 | 单个内层区间会漏算 | 分割区域 |
| 左右边界在区间内部交换 | 积分限次序可能写反 | 求交点并分段 |
| 反解出现正负两个分支 | 可能选错根 | 结合原区域约束筛选 |
| 新积分限比原式复杂很多 | 换序没有降低难度 | 保留原次序或比较极坐标 |
| 图形看似对称但不确定 | 可能误判区域 | 回到原不等式和边界方程验证 |

## 10. 双版本作答

### 练习版

1. 将原积分写成区域不等式。
2. 画出区域并标出全部交点。
3. 确定新外层变量的投影范围。
4. 反解边界曲线，确定新内层变量的左右边界。
5. 检查切片是否连续，判断是否分段。
6. 写出新积分。
7. 若题目要求计算，再按新次序计算并核验。

### 考场版

先说明原积分对应区域：

\[
D=\{(x,y)\mid 0\le x\le1,\ x^2\le y\le x\}.
\]

由 \(x^2\le y\le x\) 且 \(0\le x\le1\)，得：

\[
0\le y\le1,\qquad y\le x\le\sqrt y.
\]

因此：

\[
\int_0^1\int_{x^2}^{x}f(x,y)\,\mathrm dy\,\mathrm dx
=
\int_0^1\int_y^{\sqrt y}f(x,y)\,\mathrm dx\,\mathrm dy.
\]

### 最低有效作答

如果不能完成全部换序，至少写出：

- 原积分对应的不等式区域；
- 边界曲线及其交点；
- 新外层变量的正确投影范围；
- 能确认的边界反解关系。

不要只交换两个积分号。

## 11. 例题验证

### 例 1：标准题——区域整体换序

将下列积分改变积分次序：

\[
I=\int_0^1\int_{x^2}^{x}f(x,y)\,\mathrm dy\,\mathrm dx.
\]

**第一步：区域表达。**

\[
D=\{(x,y)\mid 0\le x\le1,\ x^2\le y\le x\}.
\]

**第二步：确定 \(y\) 的范围。**

区域最低点的纵坐标为 \(0\)，最高点为 \(1\)，所以：

\[
0\le y\le1.
\]

**第三步：固定 \(y\)，确定 \(x\) 的范围。**

由：

\[
x^2\le y\Longrightarrow x\le\sqrt y
\]

其中使用 \(x\ge0\)；又由 \(y\le x\)，得 \(x\ge y\)。因此：

\[
y\le x\le\sqrt y.
\]

**答案：**

\[
\boxed{
I=\int_0^1\int_y^{\sqrt y}f(x,y)\,\mathrm dx\,\mathrm dy
}
\]

### 例 2：变式题——利用换序计算

计算：

\[
I=\int_0^1\int_{x^2}^{x}x\,\mathrm dy\,\mathrm dx.
\]

原次序计算也可以：

\[
I=\int_0^1x(x-x^2)\,\mathrm dx
=\int_0^1(x^2-x^3)\,\mathrm dx
=\frac1{12}.
\]

换序后：

\[
\begin{aligned}
I
&=\int_0^1\int_y^{\sqrt y}x\,\mathrm dx\,\mathrm dy\\
&=\frac12\int_0^1\left(y-y^2\right)\,\mathrm dy\\
&=\frac12\left(\frac12-\frac13\right)\\
&=\frac1{12}.
\end{aligned}
\]

新旧次序结果一致。

### 例 3：综合题——换序后必须分段

设区域由 \(y=0\)、\(x=0\)、\(x=1\) 和 \(y=2-x\) 围成，计算：

\[
I=\iint_D 1\,\mathrm d\sigma.
\]

**竖直切片：**

\[
D=\{(x,y)\mid 0\le x\le1,\ 0\le y\le2-x\}.
\]

\[
I=\int_0^1\int_0^{2-x}1\,\mathrm dy\,\mathrm dx
=\int_0^1(2-x)\,\mathrm dx
=\frac32.
\]

**水平切片：**区域最高点为 \(y=2\)。当 \(0\le y\le1\) 时，水平线从 \(x=0\) 到 \(x=1\)；当 \(1\le y\le2\) 时，水平线从 \(x=0\) 到 \(x=2-y\)。因此：

\[
\begin{aligned}
I
&=\int_0^1\int_0^1 1\,\mathrm dx\,\mathrm dy
+\int_1^2\int_0^{2-y}1\,\mathrm dx\,\mathrm dy\\
&=1+\int_1^2(2-y)\,\mathrm dy\\
&=1+\frac12\\
&=\frac32.
\end{aligned}
\]

这个例子说明：换序后边界表达可能改变，必须按切片结构分段。

## 12. 常见错误与验收

### 常见错误

1. **只换微分顺序，不换积分限。**积分区域因此发生变化。
2. **把曲线反解后直接当成上下限。**水平切片应确定左右边界，且必须核对顺序。
3. **忽略原区域对变量的约束。**例如 \(x^2\le y\) 反解时，不能脱离 \(x\ge0\) 就直接选 \(+\sqrt y\)。
4. **漏掉分段点。**边界切换处必须拆分积分。
5. **误把边界交点当作唯一投影端点。**投影范围要看整个区域。
6. **为了换序而换序。**若新积分更复杂，应评估是否值得。
7. **将换序与变量代换混淆。**换序改变的是区域切片描述，不改变坐标变量本身。

### 验收清单

- [ ] 原积分正确转化为区域不等式；
- [ ] 区域边界和交点全部识别；
- [ ] 新外层变量投影范围正确；
- [ ] 新内层变量左右边界正确；
- [ ] 多值反解选取了符合区域的分支；
- [ ] 边界切换处已分段；
- [ ] 新旧积分描述同一个区域；
- [ ] 若进行了计算，结果已复核。

## 考场速查

**改变积分次序 = 还原区域 → 换方向切片 → 重写积分限。**

1. 原积分限写成不等式。
2. 画区域，标交点。
3. 确定新外层变量范围。
4. 反解边界，固定外层变量找左右界。
5. 检查是否断开、是否需要分段。
6. 写新积分并检查区域一致。

**关键提醒：**换序不是交换两个积分号，而是对同一个区域重新描述。
