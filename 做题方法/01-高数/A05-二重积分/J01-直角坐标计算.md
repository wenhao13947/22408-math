# J01｜直角坐标下二重积分计算

> 版本：V1.0  
> 状态：初稿，待与 J02—J06 进行模块级综合验证  
> 适用目标：识别区域、正确建立直角坐标积分限，并稳定完成累次积分计算。

## 1. 题型定位

二重积分的基本任务是把平面区域上的累积量转化为两次定积分：

\[
\iint_D f(x,y)\,\mathrm d\sigma
\]

在直角坐标下，常见写法有两类：

**先对 \(y\) 积分，再对 \(x\) 积分（竖直切片）：**

\[
\iint_D f(x,y)\,\mathrm d\sigma
=\int_a^b\left[\int_{\varphi_1(x)}^{\varphi_2(x)}
f(x,y)\,\mathrm dy\right]\mathrm dx.
\]

**先对 \(x\) 积分，再对 \(y\) 积分（水平切片）：**

\[
\iint_D f(x,y)\,\mathrm d\sigma
=\int_c^d\left[\int_{\psi_1(y)}^{\psi_2(y)}
f(x,y)\,\mathrm dx\right]\mathrm dy.
\]

核心不是背积分次序，而是把区域 \(D\) 描述正确。

## 2. 题型识别：看到什么，想到什么

| 题目特征 | 数学结构 | 首先想到的动作 |
|---|---|---|
| 给出 \(a\le x\le b\)，且 \(y\) 夹在两条曲线之间 | 竖直简单区域 | 直接写 \(\mathrm dy\,\mathrm dx\) |
| 给出 \(c\le y\le d\)，且 \(x\) 夹在两条曲线之间 | 水平简单区域 | 直接写 \(\mathrm dx\,\mathrm dy\) |
| 区域由直线、抛物线、圆弧围成 | 曲线围成的平面区域 | 先画草图，求交点和投影范围 |
| 同一条竖直线与区域相交成两段 | 不是单个竖直简单区域 | 考虑分割区域或改变积分次序 |
| 被积函数含 \(x^m y^n\)、多项式或可分离因子 | 直角坐标可能便于积分 | 比较内层积分的复杂度 |
| 区域关于坐标轴或原点对称 | 区域具有对称结构 | 先检查 J04 对称性，再决定是否直接计算 |

**关键提醒：**“区域看起来像矩形”不等于积分限可以直接写成矩形；必须确认每一个切片都完整落在区域内。

## 3. 目标分析

建立积分限前，先回答四个问题：

1. \(x\) 的完整取值范围是什么？或 \(y\) 的完整取值范围是什么？
2. 固定一个外层变量后，内层变量从哪条边界走到哪条边界？
3. 每个切片是否连续、是否只穿过区域的一段？
4. 被积函数对哪个变量先积分更简单？

若一个方向的切片会断开，不能硬写成一个上下限连续区间；应分割区域或改变积分次序。

## 4. 条件挖掘

把题目给出的边界条件转成积分限：

| 题目条件 | 数学含义 | 操作 |
|---|---|---|
| \(x=a,\ x=b\) | 左右边界或外层投影端点 | 确认 \(a\le x\le b\) |
| \(y=g_1(x),\ y=g_2(x)\) | 竖直方向的上下边界 | 比较大小，写成下限与上限 |
| \(y=c,\ y=d\) | 下上边界或外层投影端点 | 确认 \(c\le y\le d\) |
| \(x=h_1(y),\ x=h_2(y)\) | 水平方向的左右边界 | 比较大小，写成左限与右限 |
| 两曲线交点 | 边界顺序可能发生变化 | 解方程求交点，必要时分段 |
| 不等式 \(F(x,y)\ge0\) | 区域位于曲线 \(F=0\) 的某一侧 | 取测试点判断保留哪一侧 |

### 必做：求交点并判断边界顺序

若两条边界为 \(y=g_1(x)\) 和 \(y=g_2(x)\)，先解：

\[
g_1(x)=g_2(x).
\]

在交点之间选取测试值 \(x_0\)，比较 \(g_1(x_0)\) 与 \(g_2(x_0)\)。不能只凭图形印象判断上下关系。

## 5. 知识联想

- **定积分上下限：**内层积分的下限必须小于上限；若曲线顺序变化，应分段。
- **曲线交点：**决定投影区间端点，也可能决定分割线。
- **奇偶性与对称性：**区域和被积函数同时满足对应条件时，才可使用 J04。
- **改变积分次序：**当前方向切片断开或积分困难时，调用 J02。
- **极坐标：**圆盘、扇形或径向边界明显时，调用 J03 比较是否更简洁。
- **复杂区域分割：**两种方向都不适合一次描述时，调用 J05。

## 6. 路线选择

### 路线 A：竖直切片，写成 \(\mathrm dy\,\mathrm dx\)

适用条件：区域可表示为

\[
D=\{(x,y)\mid a\le x\le b,\ \varphi_1(x)\le y\le\varphi_2(x)\}.
\]

执行：

1. 求区域在 \(x\) 轴上的投影 \([a,b]\)。
2. 固定 \(x\)，从下边界向上边界描述区域。
3. 写出内层 \(\mathrm dy\) 积分。
4. 最后对 \(x\) 积分。

优点：适合上下边界容易识别的区域。风险：某些 \(x\) 对应的切片可能断开。

### 路线 B：水平切片，写成 \(\mathrm dx\,\mathrm dy\)

适用条件：区域可表示为

\[
D=\{(x,y)\mid c\le y\le d,\ \psi_1(y)\le x\le\psi_2(y)\}.
\]

执行：

1. 求区域在 \(y\) 轴上的投影 \([c,d]\)。
2. 固定 \(y\)，从左边界向右边界描述区域。
3. 写出内层 \(\mathrm dx\) 积分。
4. 最后对 \(y\) 积分。

### 路线 C：先分割，再分别建立积分

当竖直切片或水平切片的边界发生切换时，将区域拆成若干简单区域：

\[
D=D_1\cup D_2,\qquad
\iint_D f\,\mathrm d\sigma
=\iint_{D_1}f\,\mathrm d\sigma+\iint_{D_2}f\,\mathrm d\sigma,
\]

前提是各子区域内部不重叠，边界重合部分面积为零。

**选择原则：**先比较 A、B 哪个方向切片更简单；若都需要分段，比较分段数量和内层积分难度。不要为了少写一个积分而选择极难计算的积分次序。

## 7. 完整操作流程

### 第一步：画区域草图

标出坐标轴、所有边界曲线、交点和阴影区域。草图用于辅助判断，最终积分限仍要由方程和不等式确认。

### 第二步：确定投影范围

竖直切片求 \(x\) 的投影；水平切片求 \(y\) 的投影。投影端点通常来自边界交点或区域最左、最右、最低、最高点。

### 第三步：固定外层变量，检查切片

想象一条竖直线 \(x=x_0\) 或水平线 \(y=y_0\) 穿过区域。记录切片进入区域和离开区域的位置。

- 只穿过一段：可以用一个上下限或左右限。
- 穿过多段：当前方向不是简单区域，需要分割或换序。

### 第四步：写出累次积分

例如：

\[
\iint_D f(x,y)\,\mathrm d\sigma
=\int_a^b\int_{\varphi_1(x)}^{\varphi_2(x)}
f(x,y)\,\mathrm dy\,\mathrm dx.
\]

### 第五步：先完成内层积分

把外层变量视为常数。对 \(y\) 积分时，\(x\) 是常数；对 \(x\) 积分时，\(y\) 是常数。

### 第六步：代入内层上下限，再做外层积分

注意代入顺序为“上限值减下限值”，并保留外层变量。

### 第七步：检查结果

- 积分限是否覆盖整个区域？
- 是否漏掉或重复计算某块区域？
- 内层积分变量是否与微分符号一致？
- 结果的符号、量级是否合理？
- 若 \(f\ge0\)，积分结果是否非负？

## 8. 跨知识点连接

| 遇到的情况 | 调用模板 | 当前步骤的目的 |
|---|---|---|
| 切片边界随变量变化，且需要交换积分顺序 | J02 | 寻找更简单的切片方向 |
| 区域有圆、扇形或 \(x^2+y^2\) 结构 | J03 | 检查极坐标是否简化区域与函数 |
| 区域与函数具有相同对称性 | J04 | 先化简或判断积分为零 |
| 两个方向都需多段描述 | J05 | 选择分割线，把区域拆成简单块 |

## 9. 方法切换

| 触发信号 | 不要继续做什么 | 应切换到 |
|---|---|---|
| 固定 \(x\) 后区域分成上下两段 | 不要把两段错误合并 | J02 或 J05 |
| 固定 \(y\) 后区域分成左右两段 | 不要强行写单个区间 | J02 或 J05 |
| 曲线交点使上下边界顺序改变 | 不要沿用同一组上下限 | 分段积分或 J05 |
| 圆形边界导致直角坐标根式复杂 | 不要机械展开 | J03 |
| 对称区域且被积函数为奇对称 | 不要先做冗长计算 | J04 |

## 10. 双版本作答

### 练习版：把思考写完整

1. 由边界方程和不等式确定区域 \(D\)。
2. 求边界交点，画出区域草图。
3. 比较竖直切片和水平切片，选取较简单的方向。
4. 固定外层变量，确定内层变量的连续范围。
5. 写出累次积分，并说明积分次序。
6. 先计算内层积分，再计算外层积分。
7. 检查积分限、符号和区域覆盖情况。

### 考场版：保留必要数学依据

先写区域表示，例如：

\[
D=\{(x,y)\mid 0\le x\le1,\ 0\le y\le x\}.
\]

因此：

\[
\begin{aligned}
I
&=\iint_D f(x,y)\,\mathrm d\sigma\\
&=\int_0^1\int_0^x f(x,y)\,\mathrm dy\,\mathrm dx.
\end{aligned}
\]

随后完成内外层积分。不要省略区域到积分限的关键转换。

### 最低有效作答

若无法完成计算，至少写出：

1. 正确的区域草图或边界关系；
2. 能确认的投影范围；
3. 正确的累次积分表达式；
4. 能独立确认的内层积分步骤。

不要在区域边界不确定时猜测积分限。

## 11. 例题验证

### 例 1：标准题——三角形区域

计算：

\[
I=\iint_D (x+y)\,\mathrm d\sigma,\qquad
D=\{(x,y)\mid 0\le x\le1,\ 0\le y\le x\}.
\]

**识别：**区域已直接给出竖直简单区域，适合先对 \(y\) 积分。

\[
\begin{aligned}
I
&=\int_0^1\int_0^x(x+y)\,\mathrm dy\,\mathrm dx\\
&=\int_0^1\left[xy+\frac{y^2}{2}\right]_0^x\mathrm dx\\
&=\int_0^1\frac{3x^2}{2}\,\mathrm dx\\
&=\frac12.
\end{aligned}
\]

### 例 2：变式题——上下边界需要判断

计算：

\[
I=\iint_D y\,\mathrm d\sigma,
\]

其中 \(D\) 由 \(y=x^2\) 与 \(y=x\) 围成。

**第一步：求交点。**

\[
x^2=x\Longrightarrow x=0\text{ 或 }x=1.
\]

在 \(0<x<1\) 内，\(x^2<x\)，故区域为：

\[
D=\{(x,y)\mid 0\le x\le1,\ x^2\le y\le x\}.
\]

**第二步：建立并计算积分。**

\[
\begin{aligned}
I
&=\int_0^1\int_{x^2}^{x}y\,\mathrm dy\,\mathrm dx\\
&=\frac12\int_0^1(x^2-x^4)\,\mathrm dx\\
&=\frac12\left(\frac13-\frac15\right)\\
&=\frac1{15}.
\end{aligned}
\]

### 例 3：综合题——同一区域比较两种积分次序

计算：

\[
I=\iint_D 1\,\mathrm d\sigma,
\]

其中 \(D\) 由 \(y=0\)、\(x=0\) 和 \(y=1-x\) 围成。

**竖直切片：**

\[
D=\{(x,y)\mid 0\le x\le1,\ 0\le y\le1-x\}.
\]

\[
I=\int_0^1\int_0^{1-x}1\,\mathrm dy\,\mathrm dx
=\int_0^1(1-x)\,\mathrm dx
=\frac12.
\]

**水平切片：**

同一区域也可写成：

\[
D=\{(x,y)\mid 0\le y\le1,\ 0\le x\le1-y\}.
\]

\[
I=\int_0^1\int_0^{1-y}1\,\mathrm dx\,\mathrm dy
=\frac12.
\]

两种次序结果一致，说明区域描述正确。

## 12. 常见错误与验收

### 常见错误

1. **上下限写反：**没有比较边界函数大小。修正：求交点，并在区间内部取测试值。
2. **投影范围错误：**把某条曲线的定义域误当成整个区域的投影。修正：从区域整体求最左、最右或最低、最高点。
3. **漏掉分段：**边界顺序发生变化却仍用一组积分限。修正：检查交点和切片连续性。
4. **把微分顺序写反：**内层对 \(y\) 积分，却写成 \(\mathrm dx\)。修正：积分变量与微分符号逐项对应。
5. **只画图不验证：**草图不精确导致边界判断错误。修正：用方程求交点、用测试点判定区域。
6. **忽略更优次序：**只会照题目给出的顺序计算。修正：至少快速检查另一方向是否更简单。

### 提交前验收清单

- [ ] 区域由题目条件正确确定；
- [ ] 交点求解无误；
- [ ] 投影范围完整；
- [ ] 每条切片只对应所写的连续区间；
- [ ] 内层上下限或左右限顺序正确；

- [ ] 内层和外层计算正确；
- [ ] 必要时与另一积分次序或几何面积核对。

## 考场速查

**直角坐标四步：**

1. 画区域，求交点。
2. 选切片：竖直 \(\mathrm dy\,\mathrm dx\)，水平 \(\mathrm dx\,\mathrm dy\)。
3. 固定外层变量，确认内层是单段还是多段。
4. 写积分、先内后外、检查覆盖。

**核心判据：**

- 竖直切片连续：\(\int_a^b\int_{\text{下}}^{\text{上}}\cdots\,\mathrm dy\,\mathrm dx\)。
- 水平切片连续：\(\int_c^d\int_{\text{左}}^{\text{右}}\cdots\,\mathrm dx\,\mathrm dy\)。
- 切片断开：改变次序或分割区域。
- 圆形/径向结构突出：比较极坐标。
- 对称性明显：先检查区域与被积函数是否同时满足对称条件。

> 记住：二重积分最容易丢分的不是积分运算，而是区域描述。先把区域写对，再计算。
