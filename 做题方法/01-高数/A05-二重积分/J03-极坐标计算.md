# J03｜极坐标下二重积分计算

> 版本：V1.0  
> 状态：初稿，待模块级综合验证  
> 核心目标：识别适合极坐标的区域与被积函数，正确确定角度、半径范围，并牢记面积元素中的雅可比因子 \(r\)。

---

## 1. 题型定位

当区域具有圆形、扇形或径向边界，或者被积函数主要由 \(x^2+y^2\) 构成时，极坐标可能比直角坐标更简洁。

基本变换：

\[
x=r\cos\theta,\qquad y=r\sin\theta,\qquad r\ge0.
\]

\[
x^2+y^2=r^2,\qquad
\mathrm d\sigma= \mathrm dx\,\mathrm dy=r\,\mathrm dr\,\mathrm d\theta.
\]

因此：

\[
\iint_D f(x,y)\,\mathrm d\sigma
=
\iint_{D'}f(r\cos\theta,r\sin\theta)\,r\,\mathrm dr\,\mathrm d\theta.
\]

**最重要的提醒：**面积元素必须带 \(r\)。它来自坐标变换的雅可比行列式绝对值，不是可有可无的修饰。

## 2. 题型识别

| 看到的结构 | 联想到的极坐标表达 | 判断 |
|---|---|---|
| \(x^2+y^2\le R^2\) | \(0\le r\le R\) | 圆盘，通常适合 |
| \(x^2+y^2=R^2\) | \(r=R\) | 圆周边界 |
| \(x^2+y^2\) 出现在被积函数中 | \(r^2\) | 函数可能简化 |
| \(y=mx\) 且区域在某个象限 | \(\theta=\arctan m\)（需按象限判断） | 射线边界 |
| 扇形或圆弧夹角区域 | \(\alpha\le\theta\le\beta\) | 角度范围通常简单 |
| \(x^2+y^2\le ax\) | \(r^2\le ar\cos\theta\) | 对 \(r>0\)，可化为 \(0\le r\le a\cos\theta\)，仍须判断角度范围 |
| 区域由复杂非径向曲线围成 | 可能得到复杂 \(r(\theta)\) | 不要机械使用极坐标 |

## 3. 目标分析

极坐标题必须确定：

1. **角度范围：**区域从原点看向哪些方向？
2. **半径范围：**固定方向后，从哪条边界到哪条边界？
3. **函数变换：**\(x,y\) 代换后是否简化？
4. **面积元素：**是否正确加入 \(r\)？

若区域不包含原点，也可以出现 \(r_1(\theta)\le r\le r_2(\theta)\)，不能默认半径下限总是 0。

## 4. 条件挖掘

| 题目条件 | 转化 | 注意 |
|---|---|---|
| \(x^2+y^2\le R^2\) | \(0\le r\le R\) | 圆盘 |
| \(x^2+y^2\ge R^2\) | \(r\ge R\) | 还需其他边界限制上限 |
| \(y\ge0\) | \(\sin\theta\ge0\) | 可取上半平面角度范围 |
| \(x\ge0\) | \(\cos\theta\ge0\) | 可取右半平面角度范围 |
| \(x\ge0,y\ge0\) | \(0\le\theta\le\pi/2\) | 第一象限 |
| \(y=mx\) | \(\tan\theta=m\) | 必须结合象限选择角 |
| \(x^2+y^2\le ax\) | \(r\le a\cos\theta\)（\(r>0\)） | 同时要求右端非负 |
| \(x^2+y^2\le ay\) | \(r\le a\sin\theta\)（\(r>0\)） | 同时要求右端非负 |

### 角度范围的确定

不要仅凭 \(\tan\theta\) 求角度，因为正切值无法单独确定象限。应结合 \(x,y\) 的正负或区域草图判断。

常见范围：

- 第一象限：\(0\le\theta\le\pi/2\)；
- 上半平面：\(0\le\theta\le\pi\)；
- 右半平面：\(-\pi/2\le\theta\le\pi/2\)；
- 全圆：可取 \(0\le\theta\le2\pi\)。

同一方向角区间也可整体平移 \(2\pi\)，但必须保证区域被覆盖恰好一次。

## 5. 知识联想

- 三角函数：\(x=r\cos\theta,\ y=r\sin\theta\)。
- 二次型结构：\(x^2+y^2=r^2\)。
- 雅可比：面积缩放因子为 \(r\)。
- 对称性 J04：圆盘、扇形常具有轴对称或中心对称。
- 区域分割 J05：若半径上限随角度多次切换，可按角度分段。
- 直角坐标 J01/J02：若极坐标边界过于复杂，应比较直角坐标路线。

## 6. 路线选择

### 路线 A：圆盘或扇形直接极坐标

适用：区域可写为

\[
\alpha\le\theta\le\beta,\qquad
0\le r\le R(\theta).
\]

步骤：确定角度范围，确定径向上限，变换被积函数，乘 \(r\)，积分。

### 路线 B：非原点起始的环形区域

适用：

\[
\alpha\le\theta\le\beta,\qquad
R_1(\theta)\le r\le R_2(\theta).
\]

步骤：先找内边界与外边界，再写半径上下限。注意内半径不一定是常数。

### 路线 C：按角度分段

当固定角度射线穿过区域的径向边界发生切换时，求切换角并分段积分。若分段仍很复杂，比较直角坐标或区域分割。

**选择原则：**极坐标必须让区域、函数或两者整体变简单；仅仅出现一个圆方程，不足以保证极坐标最优。

## 7. 完整操作流程

1. 画出区域，标明原点、边界、象限和角度。
2. 将每条边界转换为 \(r,\theta\) 的关系。
3. 先确定 \(\theta\) 的范围。
4. 固定 \(\theta\)，沿射线从内向外确定 \(r\) 的范围。
5. 将 \(f(x,y)\) 改写成 \(f(r\cos\theta,r\sin\theta)\)。
6. 将 \(\mathrm dx\,\mathrm dy\) 替换为 \(r\,\mathrm dr\,\mathrm d\theta\)。
7. 先对 \(r\) 积分，再对 \(\theta\) 积分。
8. 检查角度覆盖、径向边界和 \(r\) 因子。

## 8. 跨知识点连接

| 情况 | 调用 |
|---|---|
| 区域关于轴或原点对称 | J04，先判断能否消去奇函数部分 |
| 半径上限按角度切换 | J05，按角度分割 |
| 极坐标积分限反而复杂 | J01/J02，比较直角坐标 |
| 被积函数含 \(x^2+y^2\) | 代换为 \(r^2\)，再检查是否可简化 |
| 区域不包含原点 | 允许半径下限为正，不能强行写成 \(0\) |

## 9. 方法切换

| 触发信号 | 处理 |
|---|---|
| 角度范围难以表达 | 回到区域草图，按象限与射线判断 |
| 半径上限是分段函数 | 求切换角，分段积分 |
| 边界转换成 \(r(\theta)\) 后很复杂 | 比较直角坐标 |
| 被积函数代换后更复杂 | 重新比较两种坐标系 |
| 发现遗漏 \(r\) | 立即修正面积元素，再检查所有积分 |
| 区域不包含原点 | 重新确定 \(r\) 的内外边界 |

## 10. 双版本作答

### 练习版

1. 画区域并确定角度范围。
2. 将边界方程转为极坐标。
3. 确定每条射线上的半径起止值。
4. 变换被积函数。
5. 写出含雅可比因子 \(r\) 的积分。
6. 完成积分并检查结果。

### 考场版

写明：

\[
x=r\cos\theta,\quad y=r\sin\theta,\quad
\mathrm d\sigma=r\,\mathrm dr\,\mathrm d\theta.
\]

再写出区域：

\[
\alpha\le\theta\le\beta,\quad
R_1(\theta)\le r\le R_2(\theta),
\]

最后代入并计算。不要省略角度范围的来源。

### 最低有效作答

至少写出正确坐标变换、区域角度范围、径向边界和雅可比因子。若不能完成积分，也要保证积分表达式准确。

## 11. 例题验证

### 例 1：标准题——圆盘上的径向函数

计算：

\[
I=\iint_D(x^2+y^2)\,\mathrm d\sigma,\qquad
D=\{(x,y)\mid x^2+y^2\le1\}.
\]

区域为单位圆盘：

\[
0\le r\le1,\qquad0\le\theta\le2\pi.
\]

被积函数 \(x^2+y^2=r^2\)，面积元素为 \(r\,\mathrm dr\,\mathrm d\theta\)，所以：

\[
\begin{aligned}
I
&=\int_0^{2\pi}\int_0^1r^3\,\mathrm dr\,\mathrm d\theta\\
&=2\pi\cdot\frac14\\
&=\boxed{\frac{\pi}{2}}.
\end{aligned}
\]

### 例 2：变式题——第一象限四分之一圆

计算：

\[
I=\iint_D1\,\mathrm d\sigma,
\]

其中 \(D\) 为 \(x^2+y^2\le a^2\) 的第一象限部分，\(a>0\)。

\[
0\le\theta\le\frac{\pi}{2},\qquad0\le r\le a.
\]

\[
\begin{aligned}
I
&=\int_0^{\pi/2}\int_0^a r\,\mathrm dr\,\mathrm d\theta\\
&=\frac{\pi}{2}\cdot\frac{a^2}{2}\\
&=\boxed{\frac{\pi a^2}{4}}.
\end{aligned}
\]

### 例 3：综合题——圆形边界与角度限制

计算：

\[
I=\iint_D x\,\mathrm d\sigma,
\]

其中 \(D\) 由 \(x^2+y^2\le ax\) 围成，\(a>0\)。

转换边界：

\[
r^2\le ar\cos\theta.
\]

对 \(r>0\) 得：

\[
0\le r\le a\cos\theta.
\]

由于半径上限必须非负，故：

\[
-\frac{\pi}{2}\le\theta\le\frac{\pi}{2}.
\]

被积函数 \(x=r\cos\theta\)，因此：

\[
\begin{aligned}
I
&=\int_{-\pi/2}^{\pi/2}\int_0^{a\cos\theta}
r^2\cos\theta\,\mathrm dr\,\mathrm d\theta\\
&=\frac{a^3}{3}\int_{-\pi/2}^{\pi/2}\cos^4\theta\,\mathrm d\theta\\
&=\frac{a^3}{3}\cdot\frac{3\pi}{8}\\
&=\boxed{\frac{\pi a^3}{8}}.
\end{aligned}
\]

也可观察该圆盘关于 \(x\) 轴对称，\(y\) 的积分为零，但 \(x\) 不为奇函数；不能误判为积分为零。

## 12. 常见错误与验收

1. 忘记面积元素中的 \(r\)。
2. 把 \(r\) 的范围默认成 \(0\) 到常数，忽略内边界或角度依赖。
3. 只用正切求角度，不检查象限。
4. 对 \(r^2\le ar\cos\theta\) 约去 \(r\) 后，忘记 \(r=0\) 是区域中的边界点；积分中通常不影响结果，但区域描述应完整。
5. 角度范围覆盖不足或重复覆盖。
8. 多条圆/曲线边界同时约束区域时，只转换其中一条边界，导致径向范围扩大或缩小。
6. 只因出现圆方程就强行使用极坐标。
7. 把 \(x,y\) 代换正确，却忘记同时替换被积函数和面积元素。

### 验收清单

- [ ] 角度范围与区域象限一致；
- [ ] 半径上下限由边界严格推出；
- [ ] 内半径与外半径没有颠倒；
- [ ] 被积函数中的 \(x,y\) 已全部替换；
- [ ] 面积元素含 \(r\)；
- [ ] 分段角度没有遗漏或重复；
- [ ] 最终结果与几何或对称性判断相容。

## 考场速查

\[
x=r\cos\theta,\quad y=r\sin\theta,\quad
\mathrm d\sigma=r\,\mathrm dr\,\mathrm d\theta.
\]

1. 先画区域，定 \(\theta\)。
2. 固定角度，把区域的**每一条边界约束**都转成 r 的不等式；若同时有多个上界，必须取最小者，多个下界则取最大者，不能只选其中一条圆弧。2025 数二第 20 题的两圆交集正是典型陷阱。
3. 变换 \(f(x,y)\)。
4. 乘上雅可比 \(r\)。
5. 先 \(r\) 后 \(\theta\)。
6. 检查象限、分段和 \(r\) 因子。

**记忆重点：角度管方向，半径管距离，面积元素多一个 \(r\)。**
