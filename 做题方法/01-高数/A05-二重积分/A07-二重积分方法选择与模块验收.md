# A05｜二重积分方法选择与模块验收

> V1.0｜模块验收框架初稿｜J01—J06 仍需逐题复算与真题验证

## 1. 本模块的总任务
二重积分题的核心不是先背积分公式，而是先看积分区域，再决定坐标系、积分次序和区域是否需要分割。

\[
\iint_D f(x,y)\,dA
\]
需要同时确认被积函数、区域 D、积分次序和坐标变换雅可比。

## 2. 六类方法如何选择

| 题目特征 | 首选模板 | 选择理由 |
|---|---|---|
| 区域可写成简单上下限 | J01 直角坐标 | 积分限直接 |
| 当前积分限复杂，交换后简单 | J02 改变次序 | 减少分段或简化边界 |
| 圆、扇形、圆环或径向边界 | J03 极坐标 | 区域和被积函数更自然 |
| 区域及被积函数具有对称性 | J04 对称性 | 利用奇偶抵消或等分 |
| 区域边界多段、表达式切换 | J05 区域分割 | 分块后各块边界简单 |
| 同时需要多种方法 | J06 综合 | 先选主路线，再调用辅助模板 |

没有“极坐标总比直角坐标好”或“对称性总能简化”的规则。应比较实际计算量。

## 3. 区域识别的统一流程

1. 画出所有边界曲线。
2. 求曲线交点，确认边界切换位置。
3. 判断区域是否为 x-型、y-型或两者都可。
4. 写出投影区间。
5. 对每个固定 x 或 y，确定积分上下限。
6. 检查边界顺序与区域是否完全覆盖。
7. 若换序，重新画横/竖切片，不能只交换符号。

## 4. 极坐标验收

\[
x=r\cos\theta,\quad y=r\sin\theta,\quad
dxdy=r\,dr\,d\theta.
\]

必须逐项检查：
- [ ] 区域在极坐标下的 r 范围正确；
- [ ] \(\theta\) 的起止角覆盖区域且不多不少；
- [ ] 雅可比因子 r 已写入；
- [ ] 被积函数中 x、y 均已替换；
- [ ] 若区域含原点或多瓣结构，角度范围没有漏区/重区。

## 5. 对称性验收

对称性简化必须同时验证：
1. 积分区域关于相应轴或原点对称；
2. 被积函数在对应变换下的奇偶性质；
3. 变换后的积分区域不变。

仅区域对称，不足以推出某个奇函数积分为零。原点中心对称、关于 x 轴对称、关于 y 轴对称是不同条件。

## 6. 区域分割验收

分割后每一块应满足：
- 并集等于原区域；
- 两两内部不重叠；
- 公共边界只重复在零面积集合上，不影响二重积分；
- 每块积分限正确；
- 所有块均被加上且没有漏项。

## 7. 练习版与考场版

练习版：画图、求交点、写投影、比较坐标系、再完整计算。  
考场版：保留区域描述、积分限、坐标变换和关键计算。  
最低有效作答：即使积分算不完，也应写出正确区域、积分次序及雅可比。

## 8. 模块综合例题（区域与方法选择）

设 D 为第一象限内单位圆盘：
\[
D=\{(x,y):x\ge0,y\ge0,x^2+y^2\le1\}.
\]
求 \(\iint_D(x^2+y^2)dA\)。

区域为扇形，极坐标最直接：
\[
0\le r\le1,\quad0\le\theta\le\frac\pi2.
\]
被积函数变为 \(r^2\)，面积元为 \(rdrd\theta\)，故
\[
\iint_D(x^2+y^2)dA
=\int_0^{\pi/2}\int_0^1r^3drd\theta
=\frac\pi8.
\]

验收：区域角度为第一象限；径向上限为 1；雅可比 r 已乘入。
