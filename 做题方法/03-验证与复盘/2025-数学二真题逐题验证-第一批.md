## 第 1 题｜隐函数求偏导后相加

**答案：A。**

[
z+\ln z-\int_y^x e^{-t^2}dt=0.
]
分别对 x、y 求偏导：
[
(1+1/z)z_x=e^{-x^2},q\quad
(1+1/z)z_y=-e^{-y^2}.
]
故
[
z_x+z_y=\\frac z{z+1}(e^{-x^2}-e^{-y^2}),
]
选 A。

**模板映射：** A04-04 多元隐函数求导；A03-07 变上限积分求导。

## 第 2 题｜导数判极值与高阶导数判拐点

**答案：B。**

[
f(x)=\int_0^xe^{t^2}\sin t,dt,\quad
g(x)=\left(\int_0^xe^{t^2}dtight)sin^2x.
]
有
[
f'(x)=e^{x^2}\sin x,\quad f'(0)=0,\quad f''(0)=1>0,
]
所以 x=0 是 f 的极小值点。

对 g，利用 (e^{t^2}=1+O(t^2))、(sin^2x=x^2+O(x^4))：
[
\int_0^xe^{t^2}dt=x+O(x^3),\quad
g(x)=x^3+O(x^5).
]
因此 g 在 0 的左右凹凸性改变，((0,0)) 是拐点。选 B。

**模板映射：** A02-05 极值；A02-06 凹凸与拐点；A03-07 变上限积分。

## 第 3 题｜二阶常系数方程的解与反常积分收敛

**答案：C，((-2,0))。**

方程
[
y''-2ay'+(a+2)y=0
]
的特征方程为
[
r^2-2ar+(a+2)=0.
]
要使任意解的积分 (\int_0^infty y(x)dx) 均收敛，特征根必须全部具有负实部。二阶实系数方程的判定条件为
[
r_1+r_2=2a<0,q\quad r_1r_2=a+2>0.
]
即
[
-2<a<0.
]
端点检查：a=-2 时有常数解；a=0 时解含正弦、余弦项，其反常积分不收敛。故区间为 ((-2,0))。

**模板映射：** A06-04 二阶常系数线性方程；A03-10 反常积分收敛。

## 第 4 题｜高阶无穷小的等价变换

**答案：C。**

已知 (f=o(g))，且 f、g 在去心邻域内不为零。因 (g\to0)，有
[
e^g-1\sim g.
]
于是
[
\\frac{f}{e^g-1}
=\\frac fg\cdot\\frac g{e^g-1}\to0.
]
所以 (f=o(e^g-1))，选 C。

**模板映射：** A01-02 等价无穷小；A01-03 高阶无穷小运算。  
**易错点：** 先确认 (g\to0)，再使用 (e^g-1\sim g)。

## 第 5 题｜二重积分换序并按水平切片分段

**答案：A。**

原区域
[
D={(x,y):-2\le xle2, 4-x^2\le yle4}.
]
由 (4-x^2\le y) 得 (x^2ge4-y)，且 (0\le yle4)。因此固定 y 时
[
xin[-2,-\sqrt{4-y}]cup[\sqrt{4-y},2].
]
故
[
\int_0^4left[
\int_{-2}^{-\sqrt{4-y}}f(x,y)dx+
\int_{\sqrt{4-y}}^2f(x,y)dx
ight]dy,
]
选 A。

**模板映射：** A05-J02 改变积分次序；A05-J05 分段区域。  
**易错点：** 水平切片是左右两个不连通区间，不能误写成单段或直接乘 2（被积函数未必关于 y 轴对称）。

## 第 6 题｜引力做功：必须使用沿运动方向的力分量

**独立推导答案：B；公开解析 PDF 标注 A，与其自身推导矛盾。**

P 位于 ((x,0))，Q 位于 ((0,1))，距离
[
r=\sqrt{x^2+1}.
]
引力大小
[
F=\\frac G{r^2}=\\frac G{x^2+1}.
]
但 P 沿 x 轴运动，只有引力在 x 方向的分量参与功的计算。方向余弦
[
cos\theta=\\frac{x}{\sqrt{x^2+1}}.
]
故沿运动方向的引力分量大小
[
F_x=Fcos\theta
=\\frac{Gx}{(x^2+1)^{3/2}}.
]
克服引力所做的功为
[
W=\int_0^1F_xdx
=\int_0^1\\frac{Gx}{(x^2+1)^{3/2}}dx,
]
对应 B。

**答案冲突说明：** 郑州工商学院公开解析 PDF 的答案栏写 A，但同一 PDF 后续解析明确写出 (F_x=Fcos\theta)，并把功积分写成 B。快易知逐题页也给出 B 的方向分量推导。A 是把引力大小直接乘位移，遗漏方向投影；不符合功的定义 (dW=\\vec F\cdot d\\vec r)。本库以独立物理/数学推导判定 B，并把公开答案栏标为疑似答案标注错误。

**模板映射：** A03-08 定积分物理应用（变力做功）。  
**必须补入模板的检查：** 做功先写点积 (\\vec F\cdot d\\vec r)，不能把力的大小直接当作沿位移方向的分力。

## 第 7 题｜绝对值极限条件能否推出可导

题目给出四个条件，判断其中能推出 (f) 在 0 处可导的条件个数。**本报告以郑州工商学院官网 PDF 的原卷扫描图像为主版本**（PDF 第 6 页图像；页面可直接辨认四个分子），四个条件为
[
\begin{aligned}
①&\quad \lim_{x\to0}\frac{|f(x)|-f(0)}x\text{ 存在};\
②&\quad \lim_{x\to0}\frac{f(x)-|f(0)|}x\text{ 存在};\
③&\quad \lim_{x\to0}\frac{|f(x)|}x\text{ 存在};\
④&\quad \lim_{x\to0}\frac{|f(x)-f(0)|}x\text{ 存在}.
\end{aligned}
]
题干另有前提：(f) 在 0 处连续。

**独立推导：四个条件均充分，答案应为 D（4 个）；郑州工商学院 PDF 的答案栏标 B，但其解析遗漏了双侧极限的符号约束。**

- **①** 设极限存在且有限。若 (f(0)<0)，则 (|f(x)|-f(0)\to-2f(0)>0)，除以 (x) 的双侧极限不可能有限，矛盾。若 (f(0)>0)，由连续性知邻域内 (f(x)>0)，分子化为 (f(x)-f(0))，即导数定义。若 (f(0)=0)，条件成为 (|f(x)|/x) 的双侧有限极限；右侧非负、左侧非正，极限只能为 0，故 (|f(x)|/|x|\to0)，进而 (f(x)/x\to0)，可导。
- **②** 若 (f(0)<0)，分子趋于 (f(0)-|f(0)|=2f(0)
e0)，双侧有限极限不可能存在。若 (f(0)ge0)，则 (|f(0)|=f(0))，条件就是导数定义。
- **③** 极限存在且有限，先得 (|f(x)|\to0)，由连续性知 (f(0)=0)。再由右侧商非负、左侧商非正，双侧极限只能为 0，故 (f(x)/x\to0)，可导。
- **④** 令 (h(x)=|f(x)-f(0)|ge0)。若 (h(x)/x) 的双侧有限极限存在，右侧商非负、左侧商非正，故极限只能为 0。因此
  [
  \frac{|f(x)-f(0)|}{|x|}\to0,
  ]
  从而
  [
  \frac{f(x)-f(0)}x\to0,
  ]
  导数存在且为 0。

**公开解析的逻辑漏洞：** 对①、③，解析把极限值记为非零常数后讨论导数不存在，却忽略了双侧极限中右侧商与左侧商符号相反；该非零极限值本身就不可能存在。④也不能仅凭“绝对值函数可导”一句带过，应明确写出非负量除以 (x) 的左右符号夹逼。

**题面版本审计：**
- 郑州工商学院官网 PDF 原卷扫描图像（第 6 页）显示④为 (|f(x)-f(0)|/x)，本报告按此主版本推导。
- 快易知及计算机考研杂货铺等文字转录显示④为 ((|f(x)|-|f(0)|)/x)。这是不同的转录版本，不能与扫描版混写。
- 对文字转录的替代版本，若 (f(0)
e0)，由连续性知 (f) 在 0 附近与 (f(0)) 同号，故 (|f(x)|-|f(0)|=\operatorname{sgn}(f(0))(f(x)-f(0)))，该条件仍推出 (f) 可导；若 (f(0)=0)，则退化为③，也推出可导。因此两种版本的④都充分，但证明表达式不同。
- 两个版本的分母均为 (x)，不是 (|x|)。不得把分母误转录成 (|x|)。

**模板映射：** A01-01 极限定义；A02-01 导数定义；A01-04 绝对值函数极限。  
**重要方法提醒：** 遇到非负量除以 (x) 的双侧极限，必须分别检查左右符号；先判断极限值是否只能为 0，再继续推导。

## 第 8 题｜对称矩阵的正负惯性指数

**答案：D，(a<4,b<0)。**

矩阵为
[
A=\begin{pmatrix}1&2&0\2&a&0\0&0&b\end{pmatrix}.
]
前两阶主块的二次型配方：
[
x_1^2+4x_1x_2+ax_2^2
=(x_1+2x_2)^2+(a-4)x_2^2.
]
要使该块一正一负，需 (a-4<0)，即 (a<4)。再加上第三个特征值 b 为负，需 (b<0)。选 D。

**模板映射：** 线代-08 二次型惯性指数；线代-09 正定性判定。

## 第 9 题｜行等价与行空间

**答案：B。**

目标矩阵的非零行可取
[
r_1=(1,1,0,1),\quad r_2=(0,0,1,2).
]
行等价矩阵必须有相同的行空间。选项 B 的三行满足：
[
(1,1,2,5)-r_1=2r_2,\quad
(1,1,1,3)-r_1=r_2,
]
故其行空间正好由 (r_1,r_2) 张成，且秩为 2，与目标矩阵行等价。

**模板映射：** 线代-03 矩阵秩与行空间；线代-01 初等行变换。  
**易错点：** 秩相同只是必要条件，行等价还要求行空间相同。

## 第 10 题｜乘积矩阵秩差与公共非零解

**答案：D。**

已知 (r(AB)=r(BA)+1)。若 (AB) 可逆，则 A、B 均可逆，进而 BA 也可逆，秩差为 0，矛盾。因此 (r(AB)le2)，从而
[
r(BA)=r(AB)-1le1.
]
又
[
ABA=A(BA),q\quad BAB=(BA)B,
]
所以
[
r(ABA)\le r(BA)le1,\quad
r(BAB)\le r(BA)le1.
]
两个齐次方程 (ABAx=0)、(BABx=0) 的解空间维数均至少为 2。它们是三维空间中的两个子空间，交集维数至少
[
2+2-3=1,
]
故有公共非零解，选 D。

**模板映射：** 线代-03 秩不等式；线代-05 齐次方程组解空间。
