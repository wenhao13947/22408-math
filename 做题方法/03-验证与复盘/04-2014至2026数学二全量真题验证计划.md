# 2014—2026 数学（二）全量真题验证计划

> V1.0｜执行中。目标是逐年逐题核验 2014—2026 年全国硕士研究生入学考试数学（二）真题，并反向检验现有解题模板。此计划不是完成声明。

## 一、验证范围

- 年份：2014、2015、2016、2017、2018、2019、2020、2021、2022、2023、2024、2025、2026，共 13 套。
- 题型：选择题、填空题、解答题全部纳入；综合题按原卷题号记录，必要时拆分为子问，但保留原题号。
- 科目边界：只纳入数学（二）试卷。数学一、数学三、模拟题、机构改编题不得混入真题样本。
- 核验单位：每个原卷题号至少建立一条记录；同一大题的独立子问可追加子编号。

## 二、单题验收流程

1. **来源核验**：记录原卷年份、科目、题号、发布/存档机构、原始 PDF 或稳定页面链接；注明来源属于高校官网存档、官方发布或其他转载。
2. **题面核对**：检查公式、上下标、积分限、矩阵元素、图形和选项。OCR 不清楚时回看 PDF 页面图，不猜题。
3. **独立求解**：不先看网络解析，先从题目条件独立推导。
4. **答案交叉核对**：与可靠答案或解析比对；出现冲突时保留推导并复查题面、计算和答案来源。
5. **模板映射**：记录主模板、辅助模板、条件挖掘、路线选择及方法切换点。
6. **模板压力测试**：判断现有模板是否能完整指导解题；若不能，登记缺口，补充专项或修订步骤。
7. **回归复验**：修订模板后，用原题和至少一道变式重新走流程。
8. **仓库提交**：每完成一批题目即更新详细报告、总索引、缺陷日志和 README；每个文件单独提交。

## 三、来源等级

| 等级 | 来源 | 使用方式 |
|---|---|---|
| A | 教育考试主管部门或考试机构直接发布的原始材料 | 优先使用，明确标记官方原始来源 |
| B | 高校官网、大学教学部门官网公开存档 | 可作为可追溯真题样本；不得冒称教育部原版 |
| C | 可追溯的公开题库、专业资料站、可靠出版物 | 仅作题面补充或交叉核对；尽量寻找 A/B 级副本 |
| D | 论坛、个人网盘、来源不明的图片/解析 | 不单独作为已验证依据；需找到更高等级来源复核 |

说明：公开可获得的历年材料经常是高校或教学单位存档转载。报告必须如实写明实际托管来源，不把“高校官网存档”写成“教育部官网原卷”。

## 五、报告拆分建议

- 按年份建立详细报告，避免单一文件过长，文件名采用“年份-数学二真题逐题验证”。
- 总索引统一维护年份、题号、考点、模板映射、答案、来源等级和状态。
- 发现模板缺陷时，在缺陷日志登记：题目证据 → 原模板缺口 → 修订内容 → 回归题目。
- 对来源暂缺、题面模糊或答案争议题，保留“待核验”状态，不以推测填满表格。

## 六、完成标准

只有同时满足以下条件，某一年才可标记为“全卷验证完成”：

- 全部原卷题号均已登记，无遗漏；
- 每题题面可追溯，关键公式与图形已核对；
- 每题至少有独立推导或明确的客观题判定理由；
- 答案已独立复算，并对有争议项作说明；
- 每题均有主模板/辅助模板映射，或明确说明属于超纲、题面异常等特殊情况；
- 发现的模板缺口已修订并完成回归复验；
- 年度报告、总索引、缺陷日志和 README 状态一致。

> 当前总状态：2014—2026 年逐年逐题报告均已建立首轮覆盖（2014—2020、2021—2026 各年题目均有逐题报告）。2025 年第 6、7、20 题公开答案/推导冲突，2026 年第 6 题题面版本冲突均已登记；仍需高清题面复核、逐题回归模板、修订缺陷并完成跨年变式验收。
