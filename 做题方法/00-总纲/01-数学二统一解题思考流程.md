# 数学二统一解题思考流程

> V1.0｜总纲初稿｜尚待全库题目验证  
> 服务目标：帮助基础相对薄弱的考生把“读题—挖条件—联知识—选路线—规范书写—复核”变成可重复执行的步骤。

## 一、总原则：先读懂题目，再动手计算

做题不是看到关键词就套公式。任何题目先完成六个动作：

1. **明确任务**：题目要求计算、证明、判断、求参数，还是讨论解的个数？
2. **圈出条件**：已知定义域、区间、连续、可导、单调、对称、参数、初值等。
3. **翻译条件**：把文字转换成数学语言。
4. **识别结构**：看表达式、目标和限制条件共同形成什么数学结构。
5. **选择路线**：优先选择条件满足、步骤短、容易检查的方法。
6. **验收结论**：回到原题检查定义域、范围、特殊值、符号和题目要求。

## 二、完整解题流程（每道题都能照着执行）

### 第 1 步：读题并重述目标

先用一句话写出“我要得到什么”。例如：
- 求极限：确定趋近过程及结果类型；
- 求最值：确定定义域/区域、候选点和比较范围；
- 证明不等式：移项构造函数，证明其符号；
- 求方程组通解：判断相容性、主元和自由变量。

### 第 2 步：条件挖掘

把每个条件拆成三列：

| 题目给出的信息 | 数学翻译 | 可以执行的动作 |
|---|---|---|
| 在点可导 | 在该点连续 | 可用函数极限等于函数值 |
| 在闭区间连续 | 有界、取得最大最小值 | 可用最值定理 |
| 导数恒正 | 严格递增 | 比较函数值、判断根的唯一性 |
| 单调且有界数列 | 数列收敛 | 再利用递推式求极限 |
| 矩阵可逆 | 行列式非零、满秩 | 可乘逆矩阵解方程 |
| 齐次方程有非零解 | 系数矩阵秩小于未知数个数 | 判断线性相关 |

**原则：每条隐含结论都必须有前提。** 不允许把“连续”推成“可导”，把“偏导存在”推成“可微”，或把“有界”推成“有极限”。

### 第 3 步：识别题型

使用“看到什么 → 数学结构 → 对应知识 → 用途”：

| 看到什么 | 数学结构 | 知识 | 用途 |
|---|---|---|---|
| \(0/0\) | 未定式 | 因式分解、等价、泰勒、洛必达 | 求极限 |
| \(f'(x)>0\) | 导数正 | 单调性 | 比较函数值、根数 |
| \(\int_a^x f(t)dt\) | 变上限积分 | 微积分基本定理 | 求导 |
| \(Ax=b\) | 线性方程组 | 秩与消元 | 判解与通解 |
| \(|A-\lambda I|=0\) | 特征方程 | 特征值 | 对角化 |

不要只按单个词归类，要同时看目标和限制条件。

### 第 4 步：选择 A/B/C 路线

每个专项文件中的 A/B/C 是候选路线，不是固定等级：

- **A 路线：直接、标准、低风险。** 条件齐全且结构匹配时优先使用。
- **B 路线：变形、转化或分情况。** A 无法直接执行时，把题目变成熟悉结构。
- **C 路线：定理、综合或备用方法。** 前两条不合适时，调用更强工具或跨章节知识。

路线选择必须回答：
1. 为什么适用？
2. 第一步写什么？
3. 中间每一步依据是什么？
4. 哪个条件不满足时必须停止？
5. 卡住后转向哪条路线？

### 第 5 步：执行与书写

每一步至少满足一种依据：
- 定义；
- 公式；
- 定理及其前提；
- 等价变形；
- 已证明的结论。

避免“显然”“易得”掩盖关键步骤。对基础薄弱阶段，先把每个变形写完整，再逐渐压缩。

### 第 6 步：复核

统一检查：
- 变量、定义域、区间；
- 正负号、系数、次数、上下限；
- 定理使用前提；
- 参数为零、分母为零、边界点等特殊情况；
- 结果是否回答了原问题。

## 三、练习版、考场版、最低有效作答

### 练习版
目标是建立思考能力。完整写出条件翻译、方法选择理由、每一步依据、失败路线和复盘。

### 考场版
目标是在时间内稳定拿分。保留必要的定义、关键等式、定理前提和最终结论，删除重复解释，不删除决定正确性的步骤。

### 最低有效作答
不会完整解题时，只写确定正确且能得分的内容：
- 正确的定义或公式；
- 题目条件能推出的可靠结论；
- 合法的变形；
- 正确的中间方程或秩关系。

不猜答案，不虚构定理条件，不写自己无法确认的公式。

## 四、方法切换的通用规则

| 失败信号 | 不要做 | 应做 |
|---|---|---|
| 公式套用条件不满足 | 强行继续 | 回到定义或换定理 |
| 变形后更复杂 | 无限制展开 | 撤回，换变量或路线 |
| 出现特殊参数 | 直接约分 | 分情况讨论 |
| 低阶项抵消 | 继续用低阶近似 | 增加展开阶数 |
| 只证明了必要条件 | 宣称充要 | 补充充分性 |
| 只证明至多一个根 | 宣称恰有一个 | 再证明存在性 |
| 只找到若干路径相同 | 宣称多元极限存在 | 做统一估计 |

## 五、错题复盘：记录“错误发生在哪一步”

错题不只标注知识点，还要记录：
1. 读题是否遗漏条件；
2. 是否翻译错条件；
3. 是否识别错结构；
4. 是否选错路线；
5. 是否执行时计算错误；
6. 是否漏掉验收。

每次复盘只改一个明确的动作，例如“分段点必须先算左右极限”，避免写“以后认真一点”这种无法执行的结论。

## 六、全库使用规则

1. 先看本模块总流程，再看专项模板。
2. 专项模板不是背诵答案，而是解题时的步骤导航。
3. 综合题允许按需调用多个专项。
4. 初稿不能替代教材定义、定理和真题训练。
5. 每份文件须经过例题复算、反例检查、真题验证后才可升级。
